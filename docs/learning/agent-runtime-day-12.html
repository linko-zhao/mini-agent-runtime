今天只解决什么？

实现串行 MCP Client，让 Runtime 的宿主能按正确顺序初始化、列出工具并请求一次远端调用。

get_document 位于另一个服务中。客户端不能直接调用它的 Go 方法，必须先约定协议版本和能力，再收发 JSON 消息。

本地函数签名无法跨进程直接使用。Transport 负责传消息，Client 负责消息顺序与校验；业务工具和 Agent 策略仍各自保留。

固定 MCP 2025-06-18 的教学子集，使用内存 Transport。没有生产 stdio/HTTP、OAuth、服务端主动请求、多路复用或自动重连；不要自造 shutdown RPC。

先把概念说清楚

Host / Client / Server：三个职责

Host 是使用工具的应用；Client 管理一条协议会话；Server 公布并执行远端能力。

本课 Host 创建 Client，DemoServer 仅作离线夹具。

JSON-RPC：给消息加方法和编号

请求包含 jsonrpc、id、method、params；响应沿用 id，携带 result 或 error。

通知不带 id，也不接收响应。

会话状态与业务成功不同

ready 表示可以发请求；isError=true 表示一次工具业务失败。

传输/协议不确定则会话 failed，不能无判断重放请求。

失败时停在哪里？

服务已经执行读取，却返回错误的请求 ID。Client 不能确定响应属于哪个请求，因此进入 failed；后续 list/call 不再发送。重新 initialize 同一会话也被拒绝。

这些字段、接口和方法为什么存在？

Transport 与 Client 字段

Transport.Send(ctx,bytes) 交换一条完整 JSON 消息，通知返回零字节。

Client.transport 是通道，gate 串行化会话，state 为 new/ready/failed，nextID 单调分配整数 ID，toolsAvailable 记录协商能力。

NewClient / enter / leave

构造拒绝 nil，建立容量 1 的 gate，不发送消息。

每个公开操作先 enter，离开时 leave；排队取消不发送请求，不能破坏另一个操作的会话。

InitializeResult 的字段

ProtocolVersion 必须等于固定版本；Capabilities 必须是非 nil 对象，Tools 指针存在表示支持工具；ServerInfo.Name/Version 都非空。

Implementation 只存名称和版本，不存身份凭据。

Initialize 为什么是两条消息？

先 initialize 请求，带版本、空客户端 capabilities、ClientInfo{name:agent-runtime-examples,version:0.1.0}；成功后发无 ID 的 notifications/initialized。

两步都完成才 ready，初始化任何不确定失败均不可重试同会话。

request / response 与 RPCError

request 保存 JSONRPC、ID、Method、Params；response 保存原始 ID、Result、Error。

响应要求 jsonrpc=2.0、整数 ID 精确匹配、result/error 恰有一个；result 必须对象。

RPCError 必须含整型 Code 和字符串 Message，Data 保留原 JSON；Error() 只显示代码。

ListTools 与 Descriptor

ListTools(ctx,cursor) 只返回一页 ToolsPage{Tools,NextCursor}，不自动翻页。

Descriptor{Name,Description,InputSchema,Annotations} 是线协议描述，不替代 Day 08 Spec；名称非空、页内不重名、schema 顶层 type=object。

CallTool 与 ToolResult

CallTool(ctx,name,args) 的空参数归一为 {}，其余须为非 null JSON 对象，name 非空白。

ToolResult 保留 Content 全部原始块、IsError 与 StructuredContent；块至少有非空 type。

多模态先保留，Day 13 再决定如何给模型。

错误与资源边界

传输、超限或坏协议会置 failed；有效 RPCError 不自动失效，isError 也不产生 Go error。

1MiB 预算在 Send 返回后检查，不等于网络层内存限制。

真实 Transport 还负责帧大小、关闭资源和合作取消。

R1 · 构造与初始化门禁

NewClient 不发消息且拒绝 nil；初始化前 list/call 返回 ErrSessionState。初始化顺序、版本、能力和服务器信息校验通过；通知无 ID、无响应；重复初始化拒绝。

对应测试：TestDay12Constructor / TestLifecycleAndToolErrors / TestInitializeFailureNeverReplays

R2 · 工具能力不是权限

没有 tools 能力仍正常发 initialized 并进入 ready，但 list/call 返回 ErrToolsUnavailable，不发送工具请求。它不等于无用户权限。

对应测试：TestNoToolsCapability

R3 · 校验响应并阻止重放

ID/版本错误、两种字段同时有或都无、null/畸形 error、非对象 result、超过 1MiB、非法列表或内容块均按协议错误处理并 failed。传输失败保留原因并 failed；有效 RPCError 留在 ready。

对应测试：TestMalformedResponsesFailSession / TestInvalidDescriptorsAndTransportFailure / TestLifecycleAndToolErrors

R4 · 一页目录与原始结果

原样返回/回传不透明 NextCursor；Tools 必须数组，名称/Schema 合法。Content 必须数组且每块有 type，保留非文本块、structuredContent；isError 返回 Go nil error。

对应测试：TestPaginationAndStructuredContentPreserved / TestCallInputAndContentValidation / TestInvalidDescriptorsAndTransportFailure

R5 · 输入与取消

空 args→{}；非法名称、非对象参数不发送。会话串行，排队取消不发请求、不让其他调用失效；已发送后取消按传输不确定处理并 failed，原因可 errors.Is。

对应测试：TestCallInputAndContentValidation / TestCancellationAndQueuedCall

// Package mcp demonstrates the pinned MCP 2025-06-18 tool protocol.
// It is an offline teaching client, not a complete MCP transport or SDK.
package mcp

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
)

const ProtocolVersion = "2025-06-18"
const MaxResponseBytes = 1 << 20

var (
	ErrSessionState     = errors.New("mcp: invalid session state")
	ErrToolsUnavailable = errors.New("mcp: server did not advertise tools")
	ErrProtocol         = errors.New("mcp: invalid protocol response")
)

// Send receives one serialized JSON-RPC message. Requests return one response;
// notifications return no bytes. The transport must cooperate with context.
// An actual stdio/HTTP transport would also own framing, routing and cleanup.
type Transport interface {
	Send(context.Context, []byte) ([]byte, error)
}

type Implementation struct {
	Name    string `json:"name"`
	Version string `json:"version"`
}
type ToolsCapability struct {
	ListChanged bool `json:"listChanged,omitempty"`
}
type ServerCapabilities struct {
	Tools *ToolsCapability `json:"tools,omitempty"`
}
type InitializeResult struct {
	ProtocolVersion string              `json:"protocolVersion"`
	Capabilities    *ServerCapabilities `json:"capabilities"`
	ServerInfo      Implementation      `json:"serverInfo"`
}

// Descriptor is a wire format, not a replacement for tool.Spec.
// Day13 will map this data to the existing Runtime tool contract.
type Descriptor struct {
	Name        string          `json:"name"`
	Description string          `json:"description,omitempty"`
	InputSchema json.RawMessage `json:"inputSchema"`
	Annotations json.RawMessage `json:"annotations,omitempty"`
}
type ToolsPage struct {
	Tools      []Descriptor `json:"tools"`
	NextCursor string       `json:"nextCursor,omitempty"`
}
type ToolResult struct {
	// Preserve every content block, including image/resource content.
	// Do not flatten non-text blocks or treat remote text as trusted instructions.
	Content           []json.RawMessage `json:"content"`
	IsError           bool              `json:"isError,omitempty"`
	StructuredContent json.RawMessage   `json:"structuredContent,omitempty"`
}
type RPCError struct {
	Code    int             `json:"code"`
	Message string          `json:"message"`
	Data    json.RawMessage `json:"data,omitempty"`
}

func (e *RPCError) Error() string { return fmt.Sprintf("mcp: JSON-RPC error %d", e.Code) }

type request struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      uint64          `json:"id,omitempty"`
	Method  string          `json:"method"`
	Params  json.RawMessage `json:"params,omitempty"`
}
type response struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      json.RawMessage `json:"id"`
	Result  json.RawMessage `json:"result,omitempty"`
	Error   json.RawMessage `json:"error,omitempty"`
}

package mcp

import (
	"context"
	"encoding/json"
	"fmt"
	"strconv"
	"sync"

	"github.com/linko-zhao/mini-agent-runtime/internal/tool"
)

// DemoServer exposes one existing Invokable through an in-memory JSON transport.
// It is a single-session test peer, not an authenticated network MCP server.
type DemoServer struct {
	mu     sync.Mutex
	state  string
	spec   tool.Spec
	target tool.Invokable
}

func NewDemoServer(ctx context.Context, target tool.Invokable) (*DemoServer, error) {
	if target == nil {
		return nil, fmt.Errorf("mcp demo: nil target")
	}
	spec, err := target.Meta(ctx)
	if err != nil {
		return nil, err
	}
	var schema map[string]any
	if spec.Name == "" || json.Unmarshal(spec.InputSchema, &schema) != nil || schema["type"] != "object" {
		return nil, fmt.Errorf("mcp demo: invalid descriptor")
	}
	spec.InputSchema = append(json.RawMessage(nil), spec.InputSchema...)
	return &DemoServer{state: "new", spec: spec, target: target}, nil
}
func reply(id uint64, result any, rpcErr *RPCError) ([]byte, error) {
	r := response{JSONRPC: "2.0", ID: json.RawMessage(strconv.FormatUint(id, 10))}
	var err error
	if rpcErr != nil {
		r.Error, err = json.Marshal(rpcErr)
	} else {
		r.Result, err = json.Marshal(result)
	}
	if err != nil {
		return nil, err
	}
	return json.Marshal(r)
}
func textBlock(s string) json.RawMessage {
	raw, _ := json.Marshal(struct {
		Type string `json:"type"`
		Text string `json:"text"`
	}{"text", s})
	return raw
}
func (s *DemoServer) Send(ctx context.Context, payload []byte) ([]byte, error) {
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	var r request
	if err := json.Unmarshal(payload, &r); err != nil {
		return nil, err
	}
	if r.JSONRPC != "2.0" {
		return nil, fmt.Errorf("mcp demo: invalid envelope")
	}
	if r.Method == "notifications/initialized" {
		if r.ID != 0 || s.state != "initialized" {
			return nil, fmt.Errorf("mcp demo: unexpected initialized notification")
		}
		s.state = "ready"
		return nil, nil
	}
	if r.ID == 0 {
		return nil, fmt.Errorf("mcp demo: request ID required")
	}
	if r.Method == "initialize" {
		if s.state != "new" {
			return reply(r.ID, nil, &RPCError{Code: -32600, Message: "already initialized"})
		}
		var p struct {
			ProtocolVersion string `json:"protocolVersion"`
		}
		if json.Unmarshal(r.Params, &p) != nil || p.ProtocolVersion == "" {
			return reply(r.ID, nil, &RPCError{Code: -32602, Message: "protocolVersion required"})
		}
		s.state = "initialized"
		return reply(r.ID, InitializeResult{ProtocolVersion: ProtocolVersion, Capabilities: &ServerCapabilities{Tools: &ToolsCapability{}}, ServerInfo: Implementation{Name: "offline-knowledge", Version: "0.1.0"}}, nil)
	}
	if s.state != "ready" {
		return reply(r.ID, nil, &RPCError{Code: -32600, Message: "not initialized"})
	}
	switch r.Method {
	case "tools/list":
		// One page only; this fixture's server declares no pagination.
		return reply(r.ID, ToolsPage{Tools: []Descriptor{{Name: s.spec.Name, Description: s.spec.Description, InputSchema: s.spec.InputSchema}}}, nil)
	case "tools/call":
		var p struct {
			Name      string          `json:"name"`
			Arguments json.RawMessage `json:"arguments"`
		}
		if json.Unmarshal(r.Params, &p) != nil || p.Name != s.spec.Name {
			return reply(r.ID, nil, &RPCError{Code: -32602, Message: "unknown tool or invalid parameters"})
		}
		if len(p.Arguments) == 0 {
			p.Arguments = json.RawMessage("{}")
		}
		output, err := s.target.Invoke(ctx, p.Arguments)
		if ctx.Err() != nil {
			return nil, ctx.Err()
		}
		if err != nil {
			// Controlled generic result; do not expose internal backend error text.
			return reply(r.ID, ToolResult{Content: []json.RawMessage{textBlock("document tool failed")}, IsError: true}, nil)
		}
		return reply(r.ID, ToolResult{Content: []json.RawMessage{textBlock(output)}}, nil)
	default:
		return reply(r.ID, nil, &RPCError{Code: -32601, Message: "method not found"})
	}
}

func fixture(t *testing.T) *DemoServer {
	t.Helper()
	store := knowledge.NewFakeStore([]knowledge.Document{{ID: "doc-1", Summary: "MCP", Content: "existing knowledge body"}})
	s, err := NewDemoServer(context.Background(), &knowledge.GetDocument{Store: store})
	if err != nil {
		t.Fatal(err)
	}
	return s
}
func ready(t *testing.T, transport Transport) *Client {
	t.Helper()
	c, err := NewClient(transport)
	if err != nil {
		t.Fatal(err)
	}
	if _, err = c.Initialize(context.Background()); err != nil {
		t.Fatal(err)
	}
	return c
}
func decodeRequest(t *testing.T, b []byte) request {
	t.Helper()
	var r request
	if err := json.Unmarshal(b, &r); err != nil {
		t.Fatal(err)
	}
	return r
}

func TestLifecycleAndToolErrors(t *testing.T) {
	ctx := context.Background()
	server := fixture(t)
	var methods []string
	var ids []uint64
	transport := transportFunc(func(ctx context.Context, b []byte) ([]byte, error) {
		req := decodeRequest(t, b)
		methods = append(methods, req.Method)
		ids = append(ids, req.ID)
		if req.Method == "notifications/initialized" {
			var fields map[string]json.RawMessage
			_ = json.Unmarshal(b, &fields)
			if _, ok := fields["id"]; ok {
				t.Fatal("notification has an ID")
			}
		}
		return server.Send(ctx, b)
	})
	c, _ := NewClient(transport)
	if _, err := c.ListTools(ctx, ""); !errors.Is(err, ErrSessionState) || len(methods) != 0 {
		t.Fatalf("preinit: %v %v", err, methods)
	}
	init, err := c.Initialize(ctx)
	if err != nil || init.ProtocolVersion != ProtocolVersion || init.Capabilities.Tools == nil {
		t.Fatalf("%+v %v", init, err)
	}
	page, err := c.ListTools(ctx, "")
	if err != nil || len(page.Tools) != 1 || page.Tools[0].Name != "get_document" {
		t.Fatalf("%+v %v", page, err)
	}
	result, err := c.CallTool(ctx, "get_document", json.RawMessage(`{"id":"doc-1"}`))
	if err != nil || result.IsError || len(result.Content) != 1 || !strings.Contains(string(result.Content[0]), "existing knowledge body") {
		t.Fatalf("%+v %v", result, err)
	}
	result, err = c.CallTool(ctx, "get_document", json.RawMessage(`{"id":"missing"}`))
	if err != nil || !result.IsError {
		t.Fatalf("business error: %+v %v", result, err)
	}
	_, err = c.CallTool(ctx, "unknown", nil)
	var rpc *RPCError
	if !errors.As(err, &rpc) || rpc.Code != -32602 {
		t.Fatalf("RPC error: %v", err)
	}
	if _, err = c.ListTools(ctx, ""); err != nil {
		t.Fatalf("valid RPC error killed session: %v", err)
	}
	if _, err = c.Initialize(ctx); !errors.Is(err, ErrSessionState) {
		t.Fatal("reinitialized session")
	}
	if strings.Join(methods[:4], ",") != "initialize,notifications/initialized,tools/list,tools/call" || ids[0] != 1 || ids[1] != 0 || ids[2] != 2 || ids[3] != 3 {
		t.Fatalf("methods=%v IDs=%v", methods, ids)
	}

func TestCancellationAndQueuedCall(t *testing.T) {
	server := fixture(t)
	var calls atomic.Int32
	started := make(chan struct{})
	c := ready(t, transportFunc(func(ctx context.Context, b []byte) ([]byte, error) {
		req := decodeRequest(t, b)
		if req.Method != "tools/call" {
			return server.Send(ctx, b)
		}
		calls.Add(1)
		close(started)
		<-ctx.Done()
		return nil, ctx.Err()
	}))
	ctx, cancel := context.WithCancel(context.Background())
	defer cancel()
	done := make(chan error, 1)
	go func() { _, err := c.CallTool(ctx, "get_document", nil); done <- err }()
	select {
	case <-started:
	case <-time.After(time.Second):
		t.Fatal("call did not start")
	}
	queued, stop := context.WithCancel(context.Background())
	defer stop()
	queuedDone := make(chan error, 1)
	queuedStarted := make(chan struct{})
	go func() { close(queuedStarted); _, err := c.ListTools(queued, ""); queuedDone <- err }()
	<-queuedStarted
	select {
	case err := <-queuedDone:
		t.Fatalf("queued request returned before cancellation: %v", err)
	case <-time.After(5 * time.Millisecond):
	}
	stop()
	select {
	case err := <-queuedDone:
		if !errors.Is(err, context.Canceled) {
			t.Fatal(err)
		}
	case <-time.After(time.Second):
		t.Fatal("queued cancellation blocked")
	}
	cancel()
	select {
	case err := <-done:
		if !errors.Is(err, context.Canceled) {
			t.Fatal(err)
		}
	case <-time.After(time.Second):
		t.Fatal("cancel blocked")
	}
	if calls.Load() != 1 {
		t.Fatal("cancelled request sent")
	}
	if _, err := c.ListTools(context.Background(), ""); !errors.Is(err, ErrSessionState) {
		t.Fatal("ambiguous cancelled session reused")
	}
}

package mcp

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"
	"strconv"
	"strings"
)

type Client struct {
	transport      Transport
	gate           chan struct{}
	state          string
	nextID         uint64
	toolsAvailable bool
}

func NewClient(t Transport) (*Client, error) {
	if t == nil {
		return nil, fmt.Errorf("mcp: nil transport")
	}
	return &Client{transport: t, gate: make(chan struct{}, 1), state: "new"}, nil
}

// A session serializes requests. Cancellation while queued sends no message.
func (c *Client) enter(ctx context.Context) error {
	if err := ctx.Err(); err != nil {
		return err
	}
	select {
	case c.gate <- struct{}{}:
		if err := ctx.Err(); err != nil {
			<-c.gate
			return err
		}
		return nil
	case <-ctx.Done():
		return ctx.Err()
	}
}
func (c *Client) leave() { <-c.gate }
func (c *Client) protocol(message string) error {
	c.state = "failed"
	return fmt.Errorf("%w: %s", ErrProtocol, message)
}

// rpc is called with the session gate held. Transport/protocol failures mark
// the session failed because the peer may already have executed the request.
// A valid JSON-RPC error does not automatically invalidate the session.
func (c *Client) rpc(ctx context.Context, method string, params any) (json.RawMessage, error) {
	raw, err := json.Marshal(params)
	if err != nil {
		return nil, err
	}
	c.nextID++
	id := c.nextID
	message, err := json.Marshal(request{JSONRPC: "2.0", ID: id, Method: method, Params: raw})
	if err != nil {
		return nil, err
	}
	payload, err := c.transport.Send(ctx, message)
	if ctx.Err() != nil {
		err = ctx.Err()
	}
	if err != nil {
		c.state = "failed"
		return nil, fmt.Errorf("mcp transport: %w", err)
	}
	if len(payload) > MaxResponseBytes {
		return nil, c.protocol("response exceeds byte budget")
	}
	var r response
	if err = json.Unmarshal(payload, &r); err != nil {
		return nil, c.protocol("malformed JSON")
	}
	if r.JSONRPC != "2.0" || string(r.ID) != strconv.FormatUint(id, 10) {
		return nil, c.protocol("version or request ID mismatch")
	}
	if (len(r.Result) == 0) == (len(r.Error) == 0) {
		return nil, c.protocol("expected exactly one of result/error")
	}
	if len(r.Error) > 0 {
		var e RPCError
		if bytes.Equal(bytes.TrimSpace(r.Error), []byte("null")) || json.Unmarshal(r.Error, &e) != nil {
			return nil, c.protocol("invalid RPC error")
		}
		// Required error fields must actually exist, not merely decode as zero values.
		var fields struct {
			Code    *int    `json:"code"`
			Message *string `json:"message"`
		}
		if json.Unmarshal(r.Error, &fields) != nil || fields.Code == nil || fields.Message == nil {
			return nil, c.protocol("missing/invalid RPC error fields")
		}
		return nil, &e
	}
	var object map[string]json.RawMessage
	if json.Unmarshal(r.Result, &object) != nil || object == nil {
		return nil, c.protocol("expected object result")
	}
	return r.Result, nil
}

func (c *Client) Initialize(ctx context.Context) (InitializeResult, error) {
	var result InitializeResult
	if err := c.enter(ctx); err != nil {
		return result, err
	}
	defer c.leave()
	if c.state != "new" {
		return result, ErrSessionState
	}
	// Never replay initialization on an ambiguous, possibly initialized transport.
	c.state = "failed"
	raw, err := c.rpc(ctx, "initialize", struct {
		ProtocolVersion string         `json:"protocolVersion"`
		Capabilities    struct{}       `json:"capabilities"`
		ClientInfo      Implementation `json:"clientInfo"`
	}{ProtocolVersion: ProtocolVersion, ClientInfo: Implementation{Name: "agent-runtime-examples", Version: "0.1.0"}})
	if err != nil {
		return result, err
	}
	if json.Unmarshal(raw, &result) != nil || result.ProtocolVersion != ProtocolVersion || result.Capabilities == nil || result.ServerInfo.Name == "" || result.ServerInfo.Version == "" {
		return result, c.protocol("unsupported version or invalid initialize result")
	}
	notification, _ := json.Marshal(request{JSONRPC: "2.0", Method: "notifications/initialized"})
	reply, err := c.transport.Send(ctx, notification)
	if ctx.Err() != nil {
		err = ctx.Err()
	}
	if err != nil {
		return result, fmt.Errorf("mcp initialized notification: %w", err)
	}
	if len(bytes.TrimSpace(reply)) != 0 {
		return result, c.protocol("notification must not receive a response")
	}
	c.toolsAvailable = result.Capabilities.Tools != nil
	c.state = "ready"
	return result, nil
}

func (c *Client) ListTools(ctx context.Context, cursor string) (ToolsPage, error) {
	var page ToolsPage
	if err := c.enter(ctx); err != nil {
		return page, err
	}
	defer c.leave()
	if c.state != "ready" {
		return page, ErrSessionState
	}
	if !c.toolsAvailable {
		return page, ErrToolsUnavailable
	}
	raw, err := c.rpc(ctx, "tools/list", struct {
		Cursor string `json:"cursor,omitempty"`
	}{cursor})
	if err != nil {
		return page, err
	}
	if json.Unmarshal(raw, &page) != nil || page.Tools == nil {
		return page, c.protocol("tools must be an array")
	}
	seen := map[string]bool{}
	for _, d := range page.Tools {
		var schema map[string]any
		if strings.TrimSpace(d.Name) == "" || seen[d.Name] || json.Unmarshal(d.InputSchema, &schema) != nil || schema["type"] != "object" {
			return page, c.protocol("invalid/duplicate tool descriptor")
		}
		seen[d.Name] = true
	}
	return page, nil
}

func (c *Client) CallTool(ctx context.Context, name string, args json.RawMessage) (ToolResult, error) {
	var result ToolResult
	if err := c.enter(ctx); err != nil {
		return result, err
	}
	defer c.leave()
	if c.state != "ready" {
		return result, ErrSessionState
	}
	if !c.toolsAvailable {
		return result, ErrToolsUnavailable
	}
	if len(args) == 0 {
		args = json.RawMessage("{}")
	}
	var object map[string]json.RawMessage
	if strings.TrimSpace(name) == "" || json.Unmarshal(args, &object) != nil || object == nil {
		return result, fmt.Errorf("mcp: nonempty tool name and object arguments required")
	}
	raw, err := c.rpc(ctx, "tools/call", struct {
		Name      string          `json:"name"`
		Arguments json.RawMessage `json:"arguments"`
	}{name, args})
	if err != nil {
		return result, err
	}
	if json.Unmarshal(raw, &result) != nil || result.Content == nil {
		return result, c.protocol("content must be an array")
	}
	for _, block := range result.Content {
		var header struct {
			Type string `json:"type"`
		}
		if json.Unmarshal(block, &header) != nil || header.Type == "" {
			return result, c.protocol("invalid content block")
		}
	}
	// IsError is a tool execution result, not a JSON-RPC/transport error.
	return result, nil
}
