任务 C · 25 分钟：完善 Agent 生命周期

internal/agent/agent.go：初始化阶段拒绝 maxSteps <= 0；每轮模型调用前和每次工具执行前检查 ctx.Err()；若 Generate() 返回 nil, nil 则返回可判定错误；超出步数限制时返回上限错误。

internal/agent/agent.go 或 internal/agent/options.go：为工具执行增加正数超时配置；设置了超时时使用 context.WithTimeout(ctx, toolTimeout)，未配置时直接使用父 Context；每次执行结束及时调用 cancel()。使用 fmt.Errorf("tool %s: %w", name, err) 保留错误链。

// 示意片段：工具执行使用合作式取消，不负责强杀 Goroutine
toolCtx := ctx
cancel := func() {}
if toolTimeout > 0 {
    toolCtx, cancel = context.WithTimeout(ctx, toolTimeout)
}
result, err := selectedTool.Execute(toolCtx, call.Arguments)
cancel()
if ctx.Err() != nil {
    return "", ctx.Err()
}
if err != nil {
    return "", fmt.Errorf("tool %s: %w", call.Name, err)
}
_ = result // 后续沿用既有 ToolResult 回填逻辑

工程边界：Context 的取消是合作式的。忽略 ctx 的工具可能阻塞，不能通过简单增加 Goroutine 包装就声称已经实现安全终止；非可信代码执行隔离留到第六周。
