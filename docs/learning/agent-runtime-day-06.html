任务 B · 15 分钟：定义最小事件接口

新增 internal/agent/event.go，事件只包含安全元数据，不暴露 Prompt、工具参数或工具返回正文。

type EventType string
const (
    EventRunStarted EventType = "run_started"
    EventStepStarted EventType = "step_started"
    EventModelCompleted EventType = "model_completed"
    EventToolStarted EventType = "tool_started"
    EventToolCompleted EventType = "tool_completed"
    EventRunFinished EventType = "run_finished"
    EventRunFailed EventType = "run_failed"
)
type Event struct {
    Type EventType
    Step int
    At time.Time
    ToolName string
    ToolCallID string
    Duration time.Duration
    Status string
}
type EventSink interface { Emit(context.Context, Event) }

根据现有构造函数决定采用兼容的 Option 或新构造入口。Sink 可选；nil Sink 保持原有运行行为。不要引入新依赖。

任务 C · 30 分钟：在 Run 中按顺序发布事件

internal/agent/agent.gointernal/agent/event_test.go（新增或合并）

一次 Run 发布 RunStarted；每轮模型请求前发布 StepStarted，完成后发布 ModelCompleted；每个工具执行前后发布 ToolStarted / ToolCompleted；Run 返回成功时只发布一次 RunFinished，返回错误或取消时只发布一次 RunFailed。建议用命名返回值和 defer 集中处理终态，确保错误分支不漏发或重复发。

工具错误若当前策略是写入 tool 消息并交给模型处理，ToolCompleted 标记 error；只有 Run 最终返回错误才是 RunFailed。事件时间用 time.Now()，耗时用 time.Since。不要把事件回调 panic 恢复机制作为今天范围。
