今天只解决什么？

输入还是“读取 doc-1”。Day15已能用事件计算下一份状态；今天要解决的是：这次运行的当前状态由谁保存，宿主怎样更新它，取消后怎样拒收迟到结果。

把当前状态散放在多个闭包里，容易发生旧消息覆盖新消息。我们新增一个每次运行独有的 Run 对象，让所有更新经过同一个入口。

完成后：NewRun 创建独立运行，Context 把原取消信号交给下游，Apply 提交单个合法事件，Snapshot 返回独立副本。

今天不接管旧 Agent.Run，不执行真实模型或工具，也不保存 Checkpoint。自动化只修改参考 examples 和学习材料；学习者原 internal/cmd 不会被改写。

先分清三个概念

运行上下文：告诉下游什么时候停

context.Context 携带取消、截止时间及请求范围的值。“读取 doc-1”超时后，模型与工具要收到同一个信号。

本日 Run.Context() 原样返回构造时传入的 context。状态不塞进 context.Value；创建 cancel 函数的宿主负责调用它。

当前状态：记录已经接受的事实

State 记录消息、待处理调用、轮次和阶段。例如 ToolsRunning 表示已经进入工具阶段，不能因为超时就断言工具没有执行。

继续复用 Day15 的 State、Event、New 和 Advance，不再创造一套消息或阶段枚举。

更新入口：一次只接纳一个合法事件

Apply 保存合法的新状态；非法事件返回错误和当前副本，原状态不变。Snapshot 只读，不会自动处理取消。

互斥保护的是单次转换，不是“读取 → 网络调用 → 写回”的整个事务。驱动一条运行链仍由单个宿主按顺序负责。

接口为什么这样设计？

Run：每次执行的状态所有者

ctx 是传入的原 context；state 是当前 State；mu 只保护 state 的读取和转换。字段不导出，调用方只能通过方法操作。

必须使用 NewRun 返回的指针，不复制含锁的 Run，不使用零值。每个 Run 独立，底层 Model、Tool、Sink 的并发安全仍由各自契约承担。

NewRun(ctx, runID, input, maxSteps)

返回 *Run 和 error。ctx 不能为 nil；runID 不得全为空白；maxSteps 是正整数模型轮次预算，空 input 继续合法。

先拒绝 nil ctx，再检查 ctx.Err()，然后委托 Day15 New 校验身份和预算。失败返回 nil：取消/超时保留原 context 错误，其余非法构造用 ErrTransition。

Context() context.Context

原样返回保存的 context，不生成新截止时间或 cancel 函数。宿主把它交给 Generate/Execute/Invoke；方法本身没有 I/O，也不会取消任何东西。

Snapshot() State

返回当前状态的深拷贝，包括 Messages → ToolCalls → Arguments 和 Pending 字节。调用方可修改副本，不影响 Run 或其他读者。

读取不改变状态，所以 ctx 刚取消时，Snapshot 仍可能显示 ModelRunning。只有下一次 Apply 才记录观察到的取消。

Apply(Event) (State, error)

成功保存新状态并返回副本；转换错误返回当前副本和原错误。区别于纯 Advance 的“错误返回零 State”，这里必须让宿主仍能查看当前进度。

状态只接受从 New/Advance 演进的值；没有任意 State setter。事件缓冲区在 Apply 执行期间不得被调用方并发改写，返回后可以独立使用。

Apply 同步等待互斥锁，不承诺取消能打断锁等待，也不保证公平顺序。复制成本与历史大小相关；本日没有截断、内存配额或版本号。

R2 · 合法更新与失败原子性

沿 Day15 全部转换规则推进；只有 StartModel 增加轮次。Ready+StartTools、错误结果ID、终态再更新等，返回当前副本及 ErrTransition，不覆盖原状态。

预算耗尽仍返回 ErrMaxSteps，状态保持 Ready；宿主可另发 Abort("budget") → Failed。控制原因由宿主分类，Run 不接收外部 error，不自动泄露依赖错误正文。

测试：TestDay16RoundTrip、TestDay16RejectedAndOwned。

R3 · 取消检查与终态优先

先检查已是终态则拒绝；非终态再检查 ctx.Err()。发现取消时提交 Day15 Cancel，Failure="cancelled"，保留历史和 Pending，拒绝本次传入事件并返回原 context 错误。

因此 deadline 的 State.Failure 也为 cancelled，但 errors.Is(err, context.DeadlineExceeded) 仍成立。第一次取消更新带回取消错误，后续更新返回 ErrTransition。

只在检查点观察取消；取消若发生在该检查之后，当前事件仍可能提交。已完成终态不会被后来取消改写；不承诺物理时间上的全局先后。

测试：TestDay16Cancellation。deadline 传播使用可控 context 夹具；另用真正已过期的 context 验证构造拒绝。

R4 · 数据所有权

Apply 返回值、Snapshot、原 Event 缓冲区和保存的状态互不共享可变字节。ToolsPending 的 Pending 也不能与历史中的 ToolCalls 互相污染。

测试：TestDay16RejectedAndOwned。宿主可保留快照，但不能把它写回 Run 或把内存副本当持久恢复记录。

R5 · 并发更新

Apply 与 Snapshot 可并发调用；16个并发 StartModel 只能一个成功，Step=1，其余 ErrTransition。各调用方修改自己的副本不会竞争。

锁仅串行单事件；两个相同阶段的并发响应不提供去重或操作身份匹配，宿主必须单独串行驱动一条 I/O 链。

测试：TestDay16ConcurrentUpdates。

R6 · 已进入工具阶段后的取消

ToolsRunning 后取消，迟到 tool 结果不进入 Messages，Pending 保留供诊断。不能据此推断外部效果已回滚，更不能自动重新调用。

显式 Apply(Cancel) 在活 context 下可成功，但不会取消 context；宿主停止下游仍需自己的 cancel 函数。

测试：TestDay16ToolsAndExplicitCancel。Run 无外部依赖，依赖故障测试不适用于其方法；宿主的网络/执行错误仍应按前序契约另外处理。

// Package runstate models in-memory transitions. It is not a checkpoint store.
package runstate

import (
	"errors"
	"strings"

	"github.com/linko-zhao/mini-agent-runtime/internal/model"
)

type Phase string

const (
	Ready        Phase = "ready"
	ModelRunning Phase = "model_running"
	ToolsPending Phase = "tools_pending"
	ToolsRunning Phase = "tools_running"
	Completed    Phase = "completed"
	Failed       Phase = "failed"
	Cancelled    Phase = "cancelled"
)

type EventKind string

const (
	StartModel    EventKind = "start_model"
	ModelReturned EventKind = "model_returned"
	StartTools    EventKind = "start_tools"
	ToolsReturned EventKind = "tools_returned"
	Abort         EventKind = "abort"
	Cancel        EventKind = "cancel"
)

var (
	ErrTransition = errors.New("runstate: invalid transition")
	ErrMaxSteps   = errors.New("runstate: max model rounds exceeded")
)

type State struct {
	RunID           string
	Phase           Phase
	Step, MaxSteps  int
	Messages        []model.Message
	Pending         []model.ToolCall
	Result, Failure string
}
type Event struct {
	Kind     EventKind
	Response *model.Response
	Results  []model.Message
	Reason   string
}

func New(runID, input string, maxSteps int) (State, error) {
	if strings.TrimSpace(runID) == "" || maxSteps <= 0 {
		return State{}, ErrTransition
	}
	return State{RunID: runID, Phase: Ready, MaxSteps: maxSteps, Messages: []model.Message{{Role: "user", Content: input}}}, nil
}
func cloneCalls(calls []model.ToolCall) []model.ToolCall {
	if calls == nil {
		return nil
	}
	out := append([]model.ToolCall{}, calls...)
	for i := range out {
		out[i].Arguments = append([]byte(nil), out[i].Arguments...)
	}
	return out
}
func cloneMessages(ms []model.Message) []model.Message {
	if ms == nil {
		return nil
	}
	out := append([]model.Message{}, ms...)
	for i := range out {
		out[i].ToolCalls = cloneCalls(out[i].ToolCalls)
	}
	return out
}
func cloneState(s State) State {
	s.Messages = cloneMessages(s.Messages)
	s.Pending = cloneCalls(s.Pending)
	return s
}
func terminal(p Phase) bool { return p == Completed || p == Failed || p == Cancelled }

// Advance has no I/O. The host performs calls between start/returned events.
// It accepts states from New/Advance and never mutates input state/event buffers.
func Advance(current State, e Event) (State, error) {
	if terminal(current.Phase) {
		return State{}, ErrTransition
	}
	next := cloneState(current)
	switch e.Kind {
	case StartModel:
		if current.Phase != Ready {
			return State{}, ErrTransition
		}
		if current.Step >= current.MaxSteps {
			return State{}, ErrMaxSteps
		}
		next.Step++
		next.Phase = ModelRunning
	case ModelReturned:
		if current.Phase != ModelRunning || e.Response == nil || e.Response.Message.Role != "assistant" {
			return State{}, ErrTransition
		}
		msg := e.Response.Message
		ids := map[string]bool{}
		for _, call := range msg.ToolCalls {
			if call.ID == "" || strings.TrimSpace(call.Name) == "" || ids[call.ID] {
				return State{}, ErrTransition
			}
			ids[call.ID] = true
		}
		next.Messages = append(next.Messages, cloneMessages([]model.Message{msg})...)
		if len(msg.ToolCalls) == 0 {
			next.Phase = Completed
			next.Result = msg.Content
		} else {
			next.Phase = ToolsPending
			next.Pending = cloneCalls(msg.ToolCalls)
		}
	case StartTools:
		if current.Phase != ToolsPending {
			return State{}, ErrTransition
		}
		next.Phase = ToolsRunning
	case ToolsReturned:
		if current.Phase != ToolsRunning || len(e.Results) != len(current.Pending) {
			return State{}, ErrTransition
		}
		for i, msg := range e.Results {
			if msg.Role != "tool" || msg.ToolCallID != current.Pending[i].ID {
				return State{}, ErrTransition
			}
		}
		next.Messages = append(next.Messages, cloneMessages(e.Results)...)
		next.Pending = nil
		next.Phase = Ready
	case Abort:
		if strings.TrimSpace(e.Reason) == "" {
			return State{}, ErrTransition
		}
		next.Phase = Failed
		next.Failure = e.Reason
	case Cancel:
		next.Phase = Cancelled
		next.Failure = "cancelled"
	default:
		return State{}, ErrTransition
	}
	return next, nil
}

func TestDay16NewAndContext(t *testing.T) {
	ctx, cancel := context.WithCancel(context.WithValue(context.Background(), struct{}{}, "trusted"))
	defer cancel()
	r := mustRun16(t, ctx, "r16", 2)
	if r.Context() != ctx {
		t.Fatal("context was replaced")
	}
	s := r.Snapshot()
	if s.RunID != "r16" || s.Step != 0 || s.MaxSteps != 2 || s.Phase != runstate.Ready || s.Messages[0].Content != "读取 doc-1" {
		t.Fatal(s)
	}
	for _, tc := range []struct {
		ctx    context.Context
		id     string
		budget int
		want   error
	}{
		{nil, "r", 2, runstate.ErrTransition},
		{context.Background(), " ", 2, runstate.ErrTransition},
		{context.Background(), "r", 0, runstate.ErrTransition},
	} {
		r, e := runstate.NewRun(tc.ctx, tc.id, "", tc.budget)
		if r != nil || !errors.Is(e, tc.want) {
			t.Fatal(r, e)
		}
	}
	cancel()
	if r, e := runstate.NewRun(ctx, "r", "", 2); r != nil || !errors.Is(e, context.Canceled) {
		t.Fatal(r, e)
	}
}

	for _, deadline := range []bool{false, true} {
		t.Run(map[bool]string{false: "cancel", true: "deadline"}[deadline], func(t *testing.T) {
			base, cancel := context.WithCancel(context.Background())
			var ctx context.Context = base
			want := error(context.Canceled)
			if deadline {
				ctx = deadline16{base}
				want = context.DeadlineExceeded
			}
			defer cancel()
			r := mustRun16(t, ctx, "cancel", 2)
			apply16(t, r, runstate.Event{Kind: runstate.StartModel})
			cancel()
			if r.Snapshot().Phase != runstate.ModelRunning {
				t.Fatal("read must not transition")
			}
			got, e := r.Apply(runstate.Event{Kind: runstate.ModelReturned, Response: response16()})
			if !errors.Is(e, want) || got.Phase != runstate.Cancelled || len(got.Messages) != 1 || got.Failure != "cancelled" {
				t.Fatal(got, e)
			}
			if _, e = r.Apply(runstate.Event{Kind: runstate.Cancel}); !errors.Is(e, runstate.ErrTransition) {
				t.Fatal(e)
			}
		})
	}
	expired, cancel := context.WithDeadline(context.Background(), time.Unix(1, 0))
	defer cancel()
	if r, e := runstate.NewRun(expired, "r", "", 2); r != nil || !errors.Is(e, context.DeadlineExceeded) {
		t.Fatal(r, e)
	}
	ctx, c := context.WithCancel(context.Background())
	r := mustRun16(t, ctx, "terminal", 1)

	done := apply16(t, r, runstate.Event{Kind: runstate.ModelReturned, Response: &model.Response{Message: model.Message{Role: "assistant", Content: "ok"}}})

package runstate

import (
	"context"
	"sync"
)

// Run owns one in-memory State. Use its pointer; do not copy it after use.
// The zero value is not usable; construct with NewRun.
type Run struct {
	ctx   context.Context
	mu    sync.Mutex
	state State
}

// NewRun retains ctx for cancellation/deadlines, not for storing State.
// A cancelled context rejects construction; invalid identity/budget uses ErrTransition.
func NewRun(ctx context.Context, runID, input string, maxSteps int) (*Run, error) {
	if ctx == nil {
		return nil, ErrTransition
	}
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	s, err := New(runID, input, maxSteps)
	if err != nil {
		return nil, err
	}
	return &Run{ctx: ctx, state: s}, nil
}

// Context returns the original context. The host owns any cancel function.
// Model/tool I/O must use this context outside Apply, never while holding its lock.
func (r *Run) Context() context.Context { return r.ctx }

// Snapshot returns an independent copy without triggering transitions.
func (r *Run) Snapshot() State {
	r.mu.Lock()
	defer r.mu.Unlock()
	return cloneState(r.state)
}

// Apply commits exactly one valid event, or returns the unchanged current copy.
// For a nonterminal Run, observed context cancellation commits Cancel and rejects
// the event with the original context error. A terminal State is never overwritten.
// This serializes transitions, not a snapshot -> external I/O -> Apply transaction.
func (r *Run) Apply(e Event) (State, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	if terminal(r.state.Phase) {
		return cloneState(r.state), ErrTransition
	}
	if err := r.ctx.Err(); err != nil {
		next, transitionErr := Advance(r.state, Event{Kind: Cancel})
		if transitionErr != nil {
			return cloneState(r.state), transitionErr
		}
		r.state = next
		return cloneState(r.state), err
	}
	next, err := Advance(r.state, e)
	if err != nil {
		return cloneState(r.state), err
	}
	r.state = next
	return cloneState(r.state), nil
}
