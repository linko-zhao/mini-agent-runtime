### 关键问题与建议

| 优先级 | 问题、影响与证据 | 验收条件 |
| --- | --- | --- |
| P0 | `internal/agent/agent.go` 工具子 context 超时后返回 `ctx.Err()`；父 context 未取消时返回 `("", nil)`，可能把超时报告为成功。nil Response 在 `r.Message` 解引用处 panic。 | 返回可用 `errors.Is` 判断的 `context.DeadlineExceeded`，nil 响应返回明确错误；覆盖父取消、子超时及 nil 响应。 |
| P1 | 未知工具分支只赋值后 `continue`，既未回填消息也未返回错误，破坏调用与结果配对；模型错误被重试至步数耗尽并丢失错误链。现有 `TestAgentRun` 两项断言失败。 | 按第一周既有测试约定对未知工具返回错误，模型错误保留原始错误链；补充多工具和协议不变量测试。若改为回填策略，先明确契约并同步测试。 |
| P1 | 未校验 maxSteps、工具前取消和每次执行后立即 cancel；超时固定不可配置，工具执行错误当前回填文本而非 Day 04 示意的向上传递。 | 明确工具错误策略并记录；校验配置、逐工具检查取消、及时释放子 context；覆盖多工具中途取消、执行错误和超时。 |
| P1 | 事件在部分异常路径缺失或未闭合；无事件顺序、唯一终态和共享 Sink 并发测试，`docs/design.md` 为空。 | 定义每次 Run 同步顺序、终态、错误和取消状态及 Sink 并发责任；覆盖成功、工具失败、取消、模型错误、nil 响应和并发 Run。竞态测试仅证明执行到的路径。 |
| P1 | Adapter 未限制响应体、未验证缺失工具名/非法参数；工具绑定未验证名称一致。 | 加入有界读取和协议校验；校验注册名与定义名并处理不可描述工具；使用离线测试覆盖边界。 |
| P2 | Calculator 的 JSON 解码未强制 required、额外字段或整数溢出之外的 schema 约束；目前模型声明与实际执行约束可能不同。 | 第二周明确运行时参数校验、注册表和错误协议，覆盖缺失、额外及非法参数；再按计划推进 MCP。 |
