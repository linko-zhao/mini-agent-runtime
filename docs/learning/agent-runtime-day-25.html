中断状态与保存边界

今天实现带格式版本的 PauseSnapshot，让暂停请求、运行快照和可选决定能作为同一份候选数据编解码。

20分钟 Eino 阅读 · 80分钟 Go 连续练习 · 20分钟测试复盘

只保存 Checkpoint，会丢掉什么？

延续 doc-1：r25 已收到 call-1 / get_document，停在 ToolsPending；宿主保留暂停 ID、理由，可能已经记录 reviewer-1 的批准。Day17 的 Checkpoint 只含运行位置，没有暂停 ID 和审批决定。

如果只保存旧 Checkpoint，读回后不知道等待的是哪一次请求，也不知道是否已有决定。如果分次读 CurrentInterrupt 和 CurrentDecision，另一协程可能恰好消费决定，两个值还可能来自不同观察时刻。

本日用同一门禁锁捕获一份 PauseSnapshot，再编码为有界二进制数据；读回时检查格式版本和关联一致性。这样把“要保存什么”讲清，再把字节交给独立存储层。

本日没有调用持久存储、取得写入确认或重建 Run / Gate。编码成功只产生候选字节，解码成功只产生数据；两者都不证明记录新鲜、审批可信或工具尚未执行。内存消费与外部 I/O 之间的崩溃空隙仍然存在。

三个概念

  • 格式版本：描述这份数据采用哪种结构。SchemaVersion 本日只接受 1；它不是 Day18 的存储 CAS Version，也不是 State.Step。
  • 一致捕获：在同一门禁锁内读取请求与决定。PauseSnapshot 方法返回一个观察点的数据副本，避免自己拼接两次读取。
  • 保存确认：存储适配器确认一次写入的结果。今天的 Encode 还没有走到这一步，不能把字节当作保存回执。

接口卡片与保存边界

PauseSnapshot 与两个常量

SchemaVersion int：本日只允许 PauseSnapshotSchema = 1，表示数据结构版本；零值或其它版本拒绝，不自动升级。它不是 CAS 版本、模型轮次、时间或新鲜度证明。

Request PauseRequest：原请求值，含 ID、Reason 和唯一 Checkpoint。必须是 BeforeTools / ToolsPending，暂停 ID 和理由非空白；沿用原 RunID、预算与消息/调用契约。

Decision *ApprovalDecision：nil 表示尚无决定，非 nil 可为 approve 或 reject，字段与请求精确匹配。nil 与拒绝不能混为一谈；结构里不含 context、锁、Store、工具对象或执行归属。

MaxPauseSnapshotBytes：1 << 20，即 1,048,576 字节。编码结果和解码输入上限，恰等于上限不因大小拒绝；捕获与 Clone 不应用此大小限制。它不是 Gob 解码的内存/CPU硬隔离，也不是敏感数据脱敏。

(s PauseSnapshot) Clone() PauseSnapshot

复制 Request.Checkpoint 的消息、调用和参数字节，并复制可选 Decision 指针指向的值，返回与输入独立的数据。复用 Checkpoint.Clone，不改输入，不作有效性校验、保存或授权；零候选可安全 Clone。

这是值对象的所有权边界。调用方不得在 Clone / Encode 读取期间并发修改同一个输入；多个调用方可各自修改自己的输出。

(g *PauseGate) PauseSnapshot() (PauseSnapshot, error)

依赖已构造且由唯一门禁独占写入的 Run。锁内依次观察原 ctx、检查持有请求、复制请求与可选决定、校验候选、再观察 ctx；成功返回独立候选。没有请求返回零值 / ErrNoPause；原 ctx 已取消或截止时优先返回原 Canceled / DeadlineExceeded；内部候选不符下列规则则零值 / ErrInvalidPauseSnapshot。

只读，不 Apply、不消费、不清理，也不提交 Cancelled。原 ctx 取消后已有请求/决定仍保留，直至其它推进入口观察取消。等待锁不可取消、无公平性；最后检查之后仍可能取消。

捕获与 Decide / ResolveDecision 共用同一门禁协调：决定竞争时看到完整的“尚无决定”或“已记录决定”；消费竞争时得到旧的一致候选或 ErrNoPause。返回之后原运行仍可能继续，候选不是实时视图或执行许可。

候选的有限一致性规则

  1. SchemaVersion=1；Request.ID / Reason 非空白，原样保留。复用 validateCandidate：RunID 非空白、MaxSteps>0、0≤Step≤MaxSteps，边界与 Phase 对应。
  2. 必须为 CheckpointBeforeTools / ToolsPending；Result / Failure 为空；Messages 非空且第一条 Role=user，Pending 非空。
  3. 最后一条消息 Role=assistant，ToolCalls 与 Pending 长度相同；逐项 ID、Name、Arguments 内容相同。调用 ID 非空且唯一，名称非空白；参数字节不解析业务 JSON。
  4. 若有决定，其 RunID / RequestID 与当前请求精确相等，Actor / Reason 非空白，Outcome 仅允许原 approve / reject 常量。

这些规则用于发现明显错配，不重放全部历史、不验证工具参数业务语义、身份权限、记录来源或是否过期。空白校验不规范化合法字符串；Gob 字段兼容行为仍按标准库，不宣称严格拒绝所有未知字段或存在唯一规范字节表示。

EncodePauseSnapshot(s PauseSnapshot) ([]byte, error)

先按上述规则校验，再创建一条独立 Gob 流；成功返回调用方拥有的字节。校验、Gob 编码失败或结果超上限时统一返回 nil / ErrInvalidPauseSnapshot，不保留 Gob 内部错误链。

采用 Gob 是为了保留 Arguments=json.RawMessage 的字节内容，包括空白或非 JSON 字节；本层不负责 JSON 有效性。直接 JSON 重编码可能改变原参数表示，与前序按字节匹配的证据不兼容。Gob 保留内容，但空切片可能归一为 nil，不承诺内存表示或编码输出逐字稳定。

无 ctx、文件、网络或 Store 调用，不支持中途取消。大小检查发生在编码后，可能先分配较大缓冲区；宿主仍需限制数据来源和资源使用。

DecodePauseSnapshot(data []byte) (PauseSnapshot, error)

拒绝空输入或超上限输入；用独立 bytes.Reader 解一条 Gob 值，要求没有剩余字节，再按相同规则校验。截断、垃圾、尾随数据/第二条流、旧或未知格式、关联失败统一返回零候选 / ErrInvalidPauseSnapshot。

成功数据不引用输入字节，每次解码结果互相独立。没有 ctx、迁移、保存确认或恢复调用；输入在解码期间不得被并发改写。本格式面向受信宿主记录，不是任意网络文件的安全解析器；上限不替代认证、来源校验或资源隔离。

// Package runstate models in-memory transitions. It is not a checkpoint store.
package runstate

import (
	"errors"
	"strings"

	"github.com/linko-zhao/mini-agent-runtime/internal/model"
)

type Phase string

const (
	Ready        Phase = "ready"
	ModelRunning Phase = "model_running"
	ToolsPending Phase = "tools_pending"
	ToolsRunning Phase = "tools_running"
	Completed    Phase = "completed"
	Failed       Phase = "failed"
	Cancelled    Phase = "cancelled"
)

type EventKind string

const (
	StartModel    EventKind = "start_model"
	ModelReturned EventKind = "model_returned"
	StartTools    EventKind = "start_tools"
	ToolsReturned EventKind = "tools_returned"
	Abort         EventKind = "abort"
	Cancel        EventKind = "cancel"
)

var (
	ErrTransition = errors.New("runstate: invalid transition")
	ErrMaxSteps   = errors.New("runstate: max model rounds exceeded")
)

type State struct {
	RunID           string
	Phase           Phase
	Step, MaxSteps  int
	Messages        []model.Message
	Pending         []model.ToolCall
	Result, Failure string
}
type Event struct {
	Kind     EventKind
	Response *model.Response
	Results  []model.Message
	Reason   string
}

func New(runID, input string, maxSteps int) (State, error) {
	if strings.TrimSpace(runID) == "" || maxSteps <= 0 {
		return State{}, ErrTransition
	}
	return State{RunID: runID, Phase: Ready, MaxSteps: maxSteps, Messages: []model.Message{{Role: "user", Content: input}}}, nil
}
func cloneCalls(calls []model.ToolCall) []model.ToolCall {
	if calls == nil {
		return nil
	}
	out := append([]model.ToolCall{}, calls...)
	for i := range out {
		out[i].Arguments = append([]byte(nil), out[i].Arguments...)
	}
	return out
}
func cloneMessages(ms []model.Message) []model.Message {
	if ms == nil {
		return nil
	}
	out := append([]model.Message{}, ms...)
	for i := range out {
		out[i].ToolCalls = cloneCalls(out[i].ToolCalls)
	}
	return out
}
func cloneState(s State) State {
	s.Messages = cloneMessages(s.Messages)
	s.Pending = cloneCalls(s.Pending)
	return s
}
func terminal(p Phase) bool { return p == Completed || p == Failed || p == Cancelled }

// Advance has no I/O. The host performs calls between start/returned events.
// It accepts states from New/Advance and never mutates input state/event buffers.
func Advance(current State, e Event) (State, error) {
	if terminal(current.Phase) {
		return State{}, ErrTransition
	}
	next := cloneState(current)
	switch e.Kind {
	case StartModel:
		if current.Phase != Ready {
			return State{}, ErrTransition
		}
		if current.Step >= current.MaxSteps {
			return State{}, ErrMaxSteps
		}
		next.Step++
		next.Phase = ModelRunning
	case ModelReturned:
		if current.Phase != ModelRunning || e.Response == nil || e.Response.Message.Role != "assistant" {
			return State{}, ErrTransition
		}
		msg := e.Response.Message
		ids := map[string]bool{}
		for _, call := range msg.ToolCalls {
			if call.ID == "" || strings.TrimSpace(call.Name) == "" || ids[call.ID] {
				return State{}, ErrTransition
			}
			ids[call.ID] = true
		}
		next.Messages = append(next.Messages, cloneMessages([]model.Message{msg})...)
		if len(msg.ToolCalls) == 0 {
			next.Phase = Completed
			next.Result = msg.Content
		} else {
			next.Phase = ToolsPending
			next.Pending = cloneCalls(msg.ToolCalls)
		}
	case StartTools:
		if current.Phase != ToolsPending {
			return State{}, ErrTransition
		}
		next.Phase = ToolsRunning
	case ToolsReturned:
		if current.Phase != ToolsRunning || len(e.Results) != len(current.Pending) {
			return State{}, ErrTransition
		}
		for i, msg := range e.Results {
			if msg.Role != "tool" || msg.ToolCallID != current.Pending[i].ID {
				return State{}, ErrTransition
			}
		}
		next.Messages = append(next.Messages, cloneMessages(e.Results)...)
		next.Pending = nil
		next.Phase = Ready
	case Abort:
		if strings.TrimSpace(e.Reason) == "" {
			return State{}, ErrTransition
		}
		next.Phase = Failed
		next.Failure = e.Reason
	case Cancel:
		next.Phase = Cancelled
		next.Failure = "cancelled"
	default:
		return State{}, ErrTransition
	}
	return next, nil
}

// Run owns one in-memory State. Use its pointer; do not copy it after use.
// The zero value is not usable; construct with NewRun.
type Run struct {
	ctx   context.Context
	mu    sync.Mutex
	state State
}

// NewRun retains ctx for cancellation/deadlines, not for storing State.
// A cancelled context rejects construction; invalid identity/budget uses ErrTransition.
func NewRun(ctx context.Context, runID, input string, maxSteps int) (*Run, error) {
	if ctx == nil {
		return nil, ErrTransition
	}
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	s, err := New(runID, input, maxSteps)
	if err != nil {
		return nil, err
	}
	return &Run{ctx: ctx, state: s}, nil
}

// Context returns the original context. The host owns any cancel function.
// Model/tool I/O must use this context outside Apply, never while holding its lock.
func (r *Run) Context() context.Context { return r.ctx }

// Snapshot returns an independent copy without triggering transitions.
func (r *Run) Snapshot() State {
	r.mu.Lock()
	defer r.mu.Unlock()
	return cloneState(r.state)
}

// Apply commits exactly one valid event, or returns the unchanged current copy.
// For a nonterminal Run, observed context cancellation commits Cancel and rejects
// the event with the original context error. A terminal State is never overwritten.
// This serializes transitions, not a snapshot -> external I/O -> Apply transaction.
func (r *Run) Apply(e Event) (State, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	if terminal(r.state.Phase) {
		return cloneState(r.state), ErrTransition
	}
	if err := r.ctx.Err(); err != nil {
		next, transitionErr := Advance(r.state, Event{Kind: Cancel})
		if transitionErr != nil {
			return cloneState(r.state), transitionErr
		}
		r.state = next
		return cloneState(r.state), err
	}
	next, err := Advance(r.state, e)
	if err != nil {
		return cloneState(r.state), err
	}
	r.state = next
	return cloneState(r.state), nil
}

// State uses the existing message/call contract. Boundary classifies State.Phase.
type Checkpoint struct {
	Boundary CheckpointBoundary
	State    State
}

// Clone copies nested mutable state. It does not validate or authorize a checkpoint.
func (c Checkpoint) Clone() Checkpoint {
	c.State = cloneState(c.State)
	return c
}

// Checkpoint samples boundary and state under the same lock.
// It does not observe context cancellation, advance state, pause the driver,
// perform I/O, or promise that an external tool has not already taken effect.
func (r *Run) Checkpoint() (Checkpoint, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	var boundary CheckpointBoundary
	switch r.state.Phase {
	case Ready:
		boundary = CheckpointReady
	case ToolsPending:
		boundary = CheckpointBeforeTools
	case Completed, Failed, Cancelled:
		boundary = CheckpointTerminal
	default:
		return Checkpoint{}, ErrCheckpointBoundary
	}
	return Checkpoint{Boundary: boundary, State: cloneState(r.state)}, nil
}

type CheckpointStore interface {

	Save(context.Context, Checkpoint, uint64) (StoredCheckpoint, error)

// MemoryCheckpointStore is process-local and not durable. Its zero value works.
// Do not copy after use. It retains only the latest record for each exact RunID.
type MemoryCheckpointStore struct {
	mu      sync.Mutex
	records map[string]StoredCheckpoint
}

func NewMemoryCheckpointStore() *MemoryCheckpointStore { return &MemoryCheckpointStore{} }

func cloneStored(v StoredCheckpoint) StoredCheckpoint {
	v.Checkpoint = v.Checkpoint.Clone()
	return v
}
func storeContext(ctx context.Context) error {
	if ctx == nil {
		return ErrInvalidCheckpoint
	}
	return ctx.Err()
}

// validateCandidate checks only the trusted candidate envelope, not full message
// history, authorization, authenticity or an untrusted serialized payload.
func validateCandidate(cp Checkpoint) bool {
	s := cp.State
	if strings.TrimSpace(s.RunID) == "" || s.MaxSteps <= 0 || s.Step < 0 || s.Step > s.MaxSteps {
		return false
	}
	switch cp.Boundary {
	case CheckpointReady:
		return s.Phase == Ready
	case CheckpointBeforeTools:
		return s.Phase == ToolsPending
	case CheckpointTerminal:
		return terminal(s.Phase)
	default:
		return false
	}
}

func (s *MemoryCheckpointStore) Load(ctx context.Context, runID string) (StoredCheckpoint, error) {
	if err := storeContext(ctx); err != nil {
		return StoredCheckpoint{}, err
	}
	if strings.TrimSpace(runID) == "" {
		return StoredCheckpoint{}, ErrInvalidCheckpoint
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	if err := ctx.Err(); err != nil {
		return StoredCheckpoint{}, err
	}
	v, ok := s.records[runID]
	if !ok {
		return StoredCheckpoint{}, ErrCheckpointNotFound
	}
	return cloneStored(v), nil
}

// Save: expected=0 creates only if absent; otherwise it must equal current Version.
// A successful write increments Version even for identical content.
// Errors in this in-memory implementation return zero and leave stored data intact.
// Cancellation is sampled before and after locking; later cancellation can still
// accompany a committed success. The lock wait itself is not context-interruptible.
func (s *MemoryCheckpointStore) Save(ctx context.Context, cp Checkpoint, expected uint64) (StoredCheckpoint, error) {
	if err := storeContext(ctx); err != nil {
		return StoredCheckpoint{}, err
	}
	if expected == ^uint64(0) || !validateCandidate(cp) {
		return StoredCheckpoint{}, ErrInvalidCheckpoint
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	if err := ctx.Err(); err != nil {
		return StoredCheckpoint{}, err
	}
	current := s.records[cp.State.RunID]
	if current.Version != expected {
		return StoredCheckpoint{}, ErrCheckpointConflict
	}
	next := StoredCheckpoint{Version: expected + 1, Checkpoint: cp.Clone()}
	if s.records == nil {
		s.records = make(map[string]StoredCheckpoint)
	}
	s.records[cp.State.RunID] = next
	return cloneStored(next), nil
}

// PauseRequest is an owned in-memory interruption snapshot, not a saved receipt,
// an approval, a resume token or a declaration about external side effects.
type PauseRequest struct {
	ID         string
	Reason     string
	Checkpoint Checkpoint
}

// PauseGate coordinates transitions only through this gate. The host must
// transfer exclusive write ownership of the Run to ONE gate and never bypass it.
// Zero value is not usable; do not copy after use.
type PauseGate struct {
	mu       sync.Mutex
	run      *Run
	request  *PauseRequest
	decision *ApprovalDecision
}

func NewPauseGate(run *Run) (*PauseGate, error) {
	if run == nil {
		return nil, ErrInvalidPause
	}
	return &PauseGate{run: run}, nil
}

func (g *PauseGate) Snapshot() State { return g.run.Snapshot() }

func (g *PauseGate) CurrentInterrupt() (PauseRequest, bool) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.request == nil {
		return PauseRequest{}, false
	}
	out := *g.request
	out.Checkpoint = out.Checkpoint.Clone()
	return out, true
}

// Pause captures only ToolsPending, before StartTools through this gate.
// It samples the original Run context and performs no I/O or state transition.
func (g *PauseGate) Pause(id, reason string) (PauseRequest, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if err := g.run.Context().Err(); err != nil {
		return PauseRequest{}, err
	}
	if strings.TrimSpace(id) == "" || strings.TrimSpace(reason) == "" {
		return PauseRequest{}, ErrInvalidPause
	}
	if g.request != nil {
		return PauseRequest{}, ErrPaused
	}
	cp, err := g.run.Checkpoint()
	if err != nil || cp.State.Phase != ToolsPending {
		return PauseRequest{}, ErrPauseBoundary
	}
	if err := g.run.Context().Err(); err != nil {
		return PauseRequest{}, err
	}
	request := PauseRequest{ID: id, Reason: reason, Checkpoint: cp}
	g.request = &request
	out := request
	out.Checkpoint = out.Checkpoint.Clone()
	return out, nil
}

// Apply preserves Run.Apply semantics while open. During a live pause every
// event is rejected with a current owned State and ErrPaused. Observed context
// cancellation is allowed through to Run.Apply; terminal state clears the pause.
// The host may perform I/O only AFTER a successful transition; no I/O runs here.
func (g *PauseGate) Apply(e Event) (State, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.request != nil && g.run.Context().Err() == nil {
		return g.run.Snapshot(), ErrPaused
	}
	state, err := g.run.Apply(e)
	if terminal(state.Phase) {
		g.request = nil
		g.decision = nil
	}
	return state, err
}

var ErrDecisionRequired = errors.New("runstate: a recorded decision is required")

// ResolveDecision consumes the held decision and commits one transition.
// Approve starts ToolsRunning; reject commits Failed using the recorded reason.
// No external I/O runs here. The host may execute tools only after nil error AND
// ToolsRunning from this call, never by inspecting a retry's returned State alone.
func (g *PauseGate) ResolveDecision(runID, requestID string) (State, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	// Preserve Run.Apply's cancellation observation and terminal-first behavior.
	if g.run.Context().Err() != nil {
		state, err := g.run.Apply(Event{Kind: Cancel})
		if terminal(state.Phase) {
			g.request, g.decision = nil, nil
		}
		return state, err
	}
	current := g.run.Snapshot()
	if strings.TrimSpace(runID) == "" || strings.TrimSpace(requestID) == "" {
		return current, ErrInvalidDecision
	}
	if g.request == nil {
		return current, ErrNoPause
	}
	if runID != g.request.Checkpoint.State.RunID || requestID != g.request.ID {
		return current, ErrDecisionMismatch
	}
	if g.decision == nil {
		return current, ErrDecisionRequired
	}
	event := Event{Kind: StartTools}
	if g.decision.Outcome == DecisionReject {
		event = Event{Kind: Abort, Reason: g.decision.Reason}
	}
	state, err := g.run.Apply(event)
	if err == nil || terminal(state.Phase) {
		g.request, g.decision = nil, nil
	}
	return state, err
}

package runstate

import (
	"bytes"
	"encoding/gob"
	"errors"
	"strings"
)

const (
	PauseSnapshotSchema   = 1
	MaxPauseSnapshotBytes = 1 << 20
)

var ErrInvalidPauseSnapshot = errors.New("runstate: invalid pause snapshot")

// PauseSnapshot is a versioned host-owned candidate, not a saved receipt,
// restored Gate, fresh-state proof, approval credential or execution lease.
type PauseSnapshot struct {
	SchemaVersion int
	Request       PauseRequest
	Decision      *ApprovalDecision
}

// Clone copies mutable messages, calls and the optional decision.
// It does not validate, save or authorize this value.
func (s PauseSnapshot) Clone() PauseSnapshot {
	s.Request.Checkpoint = s.Request.Checkpoint.Clone()
	if s.Decision != nil {
		d := *s.Decision
		s.Decision = &d
	}
	return s
}

// PauseSnapshot captures held request and decision under the same gate lock.
// It observes cancellation without committing it; it never calls Apply or I/O.
func (g *PauseGate) PauseSnapshot() (PauseSnapshot, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if err := g.run.Context().Err(); err != nil {
		return PauseSnapshot{}, err
	}
	if g.request == nil {
		return PauseSnapshot{}, ErrNoPause
	}
	s := PauseSnapshot{SchemaVersion: PauseSnapshotSchema, Request: *g.request, Decision: g.decision}.Clone()
	if !pauseSnapshotValid(s) {
		return PauseSnapshot{}, ErrInvalidPauseSnapshot
	}
	if err := g.run.Context().Err(); err != nil {
		return PauseSnapshot{}, err
	}
	return s, nil
}

// Limited consistency checks, not full history/provenance/authorization checks.
func pauseSnapshotValid(s PauseSnapshot) bool {
	p, cp := s.Request, s.Request.Checkpoint
	st := cp.State
	if s.SchemaVersion != PauseSnapshotSchema || strings.TrimSpace(p.ID) == "" || strings.TrimSpace(p.Reason) == "" ||
		!validateCandidate(cp) || cp.Boundary != CheckpointBeforeTools || st.Phase != ToolsPending ||
		st.Result != "" || st.Failure != "" || len(st.Messages) == 0 || st.Messages[0].Role != "user" || len(st.Pending) == 0 {
		return false
	}
	last := st.Messages[len(st.Messages)-1]
	if last.Role != "assistant" || len(last.ToolCalls) != len(st.Pending) {
		return false
	}
	ids := map[string]bool{}
	for i, call := range st.Pending {
		h := last.ToolCalls[i]
		if call.ID == "" || strings.TrimSpace(call.Name) == "" || ids[call.ID] || call.ID != h.ID || call.Name != h.Name || !bytes.Equal(call.Arguments, h.Arguments) {
			return false
		}
		ids[call.ID] = true
	}
	if d := s.Decision; d != nil {
		if d.RunID != st.RunID || d.RequestID != p.ID || strings.TrimSpace(d.Actor) == "" || strings.TrimSpace(d.Reason) == "" ||
			(d.Outcome != DecisionApprove && d.Outcome != DecisionReject) {
			return false
		}
	}
	return true
}

// EncodePauseSnapshot uses a fresh gob stream and preserves argument bytes.
// No I/O/ctx is involved. This is not canonical encoding or a storage commit.
func EncodePauseSnapshot(s PauseSnapshot) ([]byte, error) {
	if !pauseSnapshotValid(s) {
		return nil, ErrInvalidPauseSnapshot
	}
	var buf bytes.Buffer
	if err := gob.NewEncoder(&buf).Encode(s); err != nil || buf.Len() > MaxPauseSnapshotBytes {
		return nil, ErrInvalidPauseSnapshot
	}
	return buf.Bytes(), nil
}

// DecodePauseSnapshot accepts one bounded host artifact, not arbitrary network
// input. Gob type/field handling remains the standard library's compatibility
// behavior; this is not an authenticated or hostile-input-safe file format.
func DecodePauseSnapshot(data []byte) (PauseSnapshot, error) {
	if len(data) == 0 || len(data) > MaxPauseSnapshotBytes {
		return PauseSnapshot{}, ErrInvalidPauseSnapshot
	}
	reader := bytes.NewReader(data)
	var out PauseSnapshot
	if err := gob.NewDecoder(reader).Decode(&out); err != nil || reader.Len() != 0 || !pauseSnapshotValid(out) {
		return PauseSnapshot{}, ErrInvalidPauseSnapshot
	}
	return out, nil
}
