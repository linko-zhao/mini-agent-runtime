人工决定与继续路径

今天实现 ResolveDecision，让已记录的批准或拒绝沿同一 Run 状态机推进一次。

记录了“同意”，下一步谁来推进？

延续 doc-1：运行 r24 的 call-1 / get_document 已停在 ToolsPending，pause-1 保存暂停位置，reviewer-1 已提交 approve。Day23 只记录决定，所以直接 Apply(StartTools) 仍返回 ErrPaused。

宿主现在需要一个明确入口：核对目标，消费当前决定，批准时进入 ToolsRunning，拒绝时进入 Failed。两个动作在同一门禁内协调，避免多个请求把一次批准反复兑换成执行机会。

本日推进的是内存状态，不在门禁内执行 I/O。宿主仅在本次 ResolveDecision 返回 nil 错误且 Phase 为 ToolsRunning 时调用工具；拒绝是正常处理结果，返回 Failed、nil。没有进程重启恢复、审批持久化或外部副作用去重。

三个概念先讲清

  • 消费决定：把一份已记录决定用于一次状态推进，并清除门禁持有的请求和决定。ResolveDecision 承担这个动作，不改变 Decide 的记录职责。
  • 执行机会：本次批准处理成功后进入 ToolsRunning，宿主才可调用执行层。它不是已执行成功的结果，更不是跨进程的永久许可。
  • 拒绝结束：把人工拒绝映射为既有 Abort 事件，得到 Failed，Failure 沿用决定理由。它不是工具错误消息，也不自动送给模型继续推理。

等价文字：宿主请求处理已记录决定，门禁将它转换为既有事件，Run 负责状态更新。成功后门禁清理一次性内存记录；真正工具调用仍由宿主完成，不把锁跨越网络请求。

图二 · doc-1 的编号运行与结果回流

① 输入：暂停 + 首份批准r24 / pause-1，Pending=[call-1]，DecisionApprove；此时旧 Apply(StartTools) 仍被拦住
↓ ResolveDecision 校验形状、当前请求、目标、决定存在
② 提交批准事件并消费Run.Apply(StartTools) → ToolsRunning、nil；Step / Messages / Pending 不变，清 request / decision
↓ 宿主检查本次 error 和 Phase，传原 ctx / Pending 给工具
③ 锁外执行 get_document取得 doc-1 body，Gate.Apply(ToolsReturned) 回填 Role=tool、ToolCallID=call-1 → Ready
↓ Apply(StartModel)，模型读取累计 Messages，再 Apply(ModelReturned)
④ 下一轮完成assistant 给出摘要 → Completed；若在步骤②消费 reject，则直接 Failed，步骤③④均不执行

反例：第一次批准已进入 ToolsRunning，第二次 ResolveDecision 返回该当前状态和 ErrNoPause。只看 Phase 会重复执行；必须先检查本次错误。拒绝返回 nil 错误但 Phase 是 Failed，也不能执行工具。

宿主分支示意（教学伪代码，非独立可运行程序）
state, err := gate.ResolveDecision("r24", "pause-1")
if err != nil { return err } // 即便 state.Phase 是 ToolsRunning，也不能执行
switch state.Phase {
case ToolsRunning:
    // 已离开门禁锁；执行器仍须遵守原 ctx、授权、调用 ID 与结果顺序契约。
    results, callErr := executor.Execute(ctx, state.Pending)
    // 宿主将成功/失败转换为相应事件；不是门禁自动执行。
case Failed:
    // 人工拒绝已成为终态，记录 state.Failure，不调用工具。
}

接口卡片：只新增一个推进入口

ResolveDecision(runID, requestID string) (State, error)

职责：处理当前已记录决定，提交一个既有状态事件并消费元数据。接收来自可信宿主的目标 ID，均要求非空白；合法字符串原样精确匹配，不 Trim 后比较。

依赖：有效的同一 PauseGate 与原始 Run context；零值不可用、使用后不可复制。复用 g.mu 覆盖校验、Run.Apply 和消费，不在锁内执行外部代码；宿主绕过入口时不保证协调。

返回：始终是独立 State，正常成功与失败均返回当前状态副本。它与 Decide 错误返回零 ApprovalDecision 的契约不同；State 用于展示现状，不能仅据 Phase 判断本次动作成功。

正常成功：approve → 委托 StartTools，ToolsRunning、nil；reject → 委托 Abort，Failed、nil，Failure 原样等于决定 Reason。两者只改既有事件负责的字段，不增加模型 Step，不改 Messages 或 Pending；成功后 request 和 decision 一同清除，旧返回副本不变。

前置规则与错误顺序

  1. 先观察原 ctx；若已取消，委托 Run.Apply(Cancel) 观察取消并按终态结果清理。非终态进入 Cancelled，返回原 Canceled / DeadlineExceeded，即使 ID 为空或没有暂停；既有终态仍由 Run.Apply 优先返回 ErrTransition，保留结果。
  2. ctx 当前有效时取得独立当前 State，空/空白目标返回既有 ErrInvalidDecision。
  3. 没有当前暂停返回 ErrNoPause；因此消费后的重试不会重新发放执行机会，ctx 有效的既有终态也是这个出口。
  4. 目标与当前暂停 RunID / ID 精确不符返回 ErrDecisionMismatch，先于“是否有决定”检查。
  5. 有目标但没有已记录决定返回新增 ErrDecisionRequired。
  6. 根据已记录 Outcome 委托一个事件；Run.Apply 自身再次观察 ctx，因此也可能在这个边界提交 Cancelled 并返回原 ctx 错误。

ctx 有效时的上述前置失败不改变状态、请求或决定。委托成功或委托返回终态时清两项；若委托返回非终态错误则保持元数据，原因原样返回，不在此重写旧转换规则。遵守唯一门禁与有效前序契约时，合法决定对应的事件满足转换前置条件。

ErrDecisionRequired 与已有错误的复用

ErrDecisionRequired 是新增可识别 sentinel：暂停尚无决定，宿主应等待 Decide，而非执行工具。空目标沿用 ErrInvalidDecision，错目标沿用 ErrDecisionMismatch，无请求沿用 ErrNoPause；用 errors.Is 判断，不绑定错误文本。

本日没有新公开数据类型、字段或构造函数，也没有可替换外部依赖。因此网络、存储、身份服务错误不在本方法内产生；这些服务的故障、超时与取消应在宿主适配层各自验证。

取消、并发与执行的边界

与 Pause / Decide / Apply 共用门禁协调；16个并发消费只允许一个成功，其余读到已消费状态和 ErrNoPause。每份返回 State 的切片/参数字节互不共享，调用方自行同步其共享变量。

ctx 在边界采样，取消与批准竞争可能是 Cancelled/原错误，或 ToolsRunning/nil；后者随后仍可取消。锁等待不支持取消，无公平性、硬中断或物理时间优先保证。执行器必须使用原 ctx 并合作停止；门禁无法回滚已发生的 I/O。

“进入 ToolsRunning → 宿主 I/O”之间仍可崩溃。没有保存确认、执行日志、幂等键传递或分布式执行归属；本日单门禁最多发放一次机会，不等于真实工具 exactly-once。元数据清除也不是持久审计归档。

// Package runstate models in-memory transitions. It is not a checkpoint store.
package runstate

import (
	"errors"
	"strings"

	"github.com/linko-zhao/mini-agent-runtime/internal/model"
)

type Phase string

const (
	Ready        Phase = "ready"
	ModelRunning Phase = "model_running"
	ToolsPending Phase = "tools_pending"
	ToolsRunning Phase = "tools_running"
	Completed    Phase = "completed"
	Failed       Phase = "failed"
	Cancelled    Phase = "cancelled"
)

type EventKind string

const (
	StartModel    EventKind = "start_model"
	ModelReturned EventKind = "model_returned"
	StartTools    EventKind = "start_tools"
	ToolsReturned EventKind = "tools_returned"
	Abort         EventKind = "abort"
	Cancel        EventKind = "cancel"
)

var (
	ErrTransition = errors.New("runstate: invalid transition")
	ErrMaxSteps   = errors.New("runstate: max model rounds exceeded")
)

type State struct {
	RunID           string
	Phase           Phase
	Step, MaxSteps  int
	Messages        []model.Message
	Pending         []model.ToolCall
	Result, Failure string
}
type Event struct {
	Kind     EventKind
	Response *model.Response
	Results  []model.Message
	Reason   string
}

func New(runID, input string, maxSteps int) (State, error) {
	if strings.TrimSpace(runID) == "" || maxSteps <= 0 {
		return State{}, ErrTransition
	}
	return State{RunID: runID, Phase: Ready, MaxSteps: maxSteps, Messages: []model.Message{{Role: "user", Content: input}}}, nil
}
func cloneCalls(calls []model.ToolCall) []model.ToolCall {
	if calls == nil {
		return nil
	}
	out := append([]model.ToolCall{}, calls...)
	for i := range out {
		out[i].Arguments = append([]byte(nil), out[i].Arguments...)
	}
	return out
}
func cloneMessages(ms []model.Message) []model.Message {
	if ms == nil {
		return nil
	}
	out := append([]model.Message{}, ms...)
	for i := range out {
		out[i].ToolCalls = cloneCalls(out[i].ToolCalls)
	}
	return out
}
func cloneState(s State) State {
	s.Messages = cloneMessages(s.Messages)
	s.Pending = cloneCalls(s.Pending)
	return s
}
func terminal(p Phase) bool { return p == Completed || p == Failed || p == Cancelled }

// Advance has no I/O. The host performs calls between start/returned events.
// It accepts states from New/Advance and never mutates input state/event buffers.
func Advance(current State, e Event) (State, error) {
	if terminal(current.Phase) {
		return State{}, ErrTransition
	}
	next := cloneState(current)
	switch e.Kind {
	case StartModel:
		if current.Phase != Ready {
			return State{}, ErrTransition
		}
		if current.Step >= current.MaxSteps {
			return State{}, ErrMaxSteps
		}
		next.Step++
		next.Phase = ModelRunning
	case ModelReturned:
		if current.Phase != ModelRunning || e.Response == nil || e.Response.Message.Role != "assistant" {
			return State{}, ErrTransition
		}
		msg := e.Response.Message
		ids := map[string]bool{}
		for _, call := range msg.ToolCalls {
			if call.ID == "" || strings.TrimSpace(call.Name) == "" || ids[call.ID] {
				return State{}, ErrTransition
			}
			ids[call.ID] = true
		}
		next.Messages = append(next.Messages, cloneMessages([]model.Message{msg})...)
		if len(msg.ToolCalls) == 0 {
			next.Phase = Completed
			next.Result = msg.Content
		} else {
			next.Phase = ToolsPending
			next.Pending = cloneCalls(msg.ToolCalls)
		}
	case StartTools:
		if current.Phase != ToolsPending {
			return State{}, ErrTransition
		}
		next.Phase = ToolsRunning
	case ToolsReturned:
		if current.Phase != ToolsRunning || len(e.Results) != len(current.Pending) {
			return State{}, ErrTransition
		}
		for i, msg := range e.Results {
			if msg.Role != "tool" || msg.ToolCallID != current.Pending[i].ID {
				return State{}, ErrTransition
			}
		}
		next.Messages = append(next.Messages, cloneMessages(e.Results)...)
		next.Pending = nil
		next.Phase = Ready
	case Abort:
		if strings.TrimSpace(e.Reason) == "" {
			return State{}, ErrTransition
		}
		next.Phase = Failed
		next.Failure = e.Reason
	case Cancel:
		next.Phase = Cancelled
		next.Failure = "cancelled"
	default:
		return State{}, ErrTransition
	}
	return next, nil
}

package runstate

import (
	"context"
	"sync"
)

// Run owns one in-memory State. Use its pointer; do not copy it after use.
// The zero value is not usable; construct with NewRun.
type Run struct {
	ctx   context.Context
	mu    sync.Mutex
	state State
}

// NewRun retains ctx for cancellation/deadlines, not for storing State.
// A cancelled context rejects construction; invalid identity/budget uses ErrTransition.
func NewRun(ctx context.Context, runID, input string, maxSteps int) (*Run, error) {
	if ctx == nil {
		return nil, ErrTransition
	}
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	s, err := New(runID, input, maxSteps)
	if err != nil {
		return nil, err
	}
	return &Run{ctx: ctx, state: s}, nil
}

// Context returns the original context. The host owns any cancel function.
// Model/tool I/O must use this context outside Apply, never while holding its lock.
func (r *Run) Context() context.Context { return r.ctx }

// Snapshot returns an independent copy without triggering transitions.
func (r *Run) Snapshot() State {
	r.mu.Lock()
	defer r.mu.Unlock()
	return cloneState(r.state)
}

// Apply commits exactly one valid event, or returns the unchanged current copy.
// For a nonterminal Run, observed context cancellation commits Cancel and rejects
// the event with the original context error. A terminal State is never overwritten.
// This serializes transitions, not a snapshot -> external I/O -> Apply transaction.
func (r *Run) Apply(e Event) (State, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	if terminal(r.state.Phase) {
		return cloneState(r.state), ErrTransition
	}
	if err := r.ctx.Err(); err != nil {
		next, transitionErr := Advance(r.state, Event{Kind: Cancel})
		if transitionErr != nil {
			return cloneState(r.state), transitionErr
		}
		r.state = next
		return cloneState(r.state), err
	}
	next, err := Advance(r.state, e)
	if err != nil {
		return cloneState(r.state), err
	}
	r.state = next
	return cloneState(r.state), nil
}

package runstate

import "errors"

type CheckpointBoundary string

const (
	CheckpointReady       CheckpointBoundary = "ready"
	CheckpointBeforeTools CheckpointBoundary = "before_tools"
	CheckpointTerminal    CheckpointBoundary = "terminal"
)

var ErrCheckpointBoundary = errors.New("runstate: checkpoint requires a stable boundary")

// Checkpoint is an in-memory candidate, not a storage acknowledgement or resume token.
// State uses the existing message/call contract. Boundary classifies State.Phase.
type Checkpoint struct {
	Boundary CheckpointBoundary
	State    State
}

// Clone copies nested mutable state. It does not validate or authorize a checkpoint.
func (c Checkpoint) Clone() Checkpoint {
	c.State = cloneState(c.State)
	return c
}

// Checkpoint samples boundary and state under the same lock.
// It does not observe context cancellation, advance state, pause the driver,
// perform I/O, or promise that an external tool has not already taken effect.
func (r *Run) Checkpoint() (Checkpoint, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	var boundary CheckpointBoundary
	switch r.state.Phase {
	case Ready:
		boundary = CheckpointReady
	case ToolsPending:
		boundary = CheckpointBeforeTools
	case Completed, Failed, Cancelled:
		boundary = CheckpointTerminal
	default:
		return Checkpoint{}, ErrCheckpointBoundary
	}
	return Checkpoint{Boundary: boundary, State: cloneState(r.state)}, nil
}

import (
	"errors"
	"strings"
	"sync"
)

var (
	ErrInvalidPause  = errors.New("runstate: invalid pause request")
	ErrPauseBoundary = errors.New("runstate: pause requires tools_pending")
	ErrPaused        = errors.New("runstate: gate is paused")
)

// PauseRequest is an owned in-memory interruption snapshot, not a saved receipt,
// an approval, a resume token or a declaration about external side effects.
type PauseRequest struct {
	ID         string
	Reason     string
	Checkpoint Checkpoint
}

// PauseGate coordinates transitions only through this gate. The host must
// transfer exclusive write ownership of the Run to ONE gate and never bypass it.
// Zero value is not usable; do not copy after use.
type PauseGate struct {
	mu       sync.Mutex
	run      *Run
	request  *PauseRequest
	decision *ApprovalDecision
}

func NewPauseGate(run *Run) (*PauseGate, error) {
	if run == nil {
		return nil, ErrInvalidPause
	}
	return &PauseGate{run: run}, nil
}

func (g *PauseGate) Snapshot() State { return g.run.Snapshot() }

func (g *PauseGate) CurrentInterrupt() (PauseRequest, bool) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.request == nil {
		return PauseRequest{}, false
	}
	out := *g.request
	out.Checkpoint = out.Checkpoint.Clone()
	return out, true
}

// Pause captures only ToolsPending, before StartTools through this gate.
// It samples the original Run context and performs no I/O or state transition.
func (g *PauseGate) Pause(id, reason string) (PauseRequest, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if err := g.run.Context().Err(); err != nil {
		return PauseRequest{}, err
	}
	if strings.TrimSpace(id) == "" || strings.TrimSpace(reason) == "" {
		return PauseRequest{}, ErrInvalidPause
	}
	if g.request != nil {
		return PauseRequest{}, ErrPaused
	}
	cp, err := g.run.Checkpoint()
	if err != nil || cp.State.Phase != ToolsPending {
		return PauseRequest{}, ErrPauseBoundary
	}
	if err := g.run.Context().Err(); err != nil {
		return PauseRequest{}, err
	}
	request := PauseRequest{ID: id, Reason: reason, Checkpoint: cp}
	g.request = &request
	out := request
	out.Checkpoint = out.Checkpoint.Clone()
	return out, nil
}

// Apply preserves Run.Apply semantics while open. During a live pause every
// event is rejected with a current owned State and ErrPaused. Observed context
// cancellation is allowed through to Run.Apply; terminal state clears the pause.
// The host may perform I/O only AFTER a successful transition; no I/O runs here.
func (g *PauseGate) Apply(e Event) (State, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.request != nil && g.run.Context().Err() == nil {
		return g.run.Snapshot(), ErrPaused
	}
	state, err := g.run.Apply(e)
	if terminal(state.Phase) {
		g.request = nil
		g.decision = nil
	}
	return state, err
}

package runstate

import (
	"errors"
	"strings"

type DecisionOutcome string

const (
	DecisionApprove DecisionOutcome = "approve"
	DecisionReject  DecisionOutcome = "reject"
)

var (
	ErrInvalidDecision  = errors.New("runstate: invalid approval decision")
	ErrNoPause          = errors.New("runstate: no held pause request")
	ErrDecisionMismatch = errors.New("runstate: decision does not match held request")
	ErrDecisionRecorded = errors.New("runstate: decision already recorded")
)

// ApprovalDecision is host-provided metadata, not proof of identity, authority,
// persistence or permission to execute. All fields are immutable value strings.
type ApprovalDecision struct {
	RunID     string
	RequestID string
	Actor     string
	Outcome   DecisionOutcome
	Reason    string
}

// Decide records the first valid decision for this gate's held pause.
// It does not unpause, execute, terminate or write a checkpoint.
func (g *PauseGate) Decide(d ApprovalDecision) (ApprovalDecision, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if err := g.run.Context().Err(); err != nil {
		return ApprovalDecision{}, err
	}
	if strings.TrimSpace(d.RunID) == "" || strings.TrimSpace(d.RequestID) == "" ||
		strings.TrimSpace(d.Actor) == "" || strings.TrimSpace(d.Reason) == "" ||
		(d.Outcome != DecisionApprove && d.Outcome != DecisionReject) {
		return ApprovalDecision{}, ErrInvalidDecision
	}
	if g.request == nil {
		return ApprovalDecision{}, ErrNoPause
	}
	if d.RunID != g.request.Checkpoint.State.RunID || d.RequestID != g.request.ID {
		return ApprovalDecision{}, ErrDecisionMismatch
	}
	if g.decision != nil {
		return ApprovalDecision{}, ErrDecisionRecorded
	}
	if err := g.run.Context().Err(); err != nil {
		return ApprovalDecision{}, err
	}
	g.decision = &d
	return d, nil
}

// CurrentDecision reads held metadata without observing cancellation.
// A terminal Apply clears it together with the held pause request.
func (g *PauseGate) CurrentDecision() (ApprovalDecision, bool) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.decision == nil {
		return ApprovalDecision{}, false
	}
	return *g.decision, true
}

package runstate

import (
	"errors"
	"strings"
)

var ErrDecisionRequired = errors.New("runstate: a recorded decision is required")

// ResolveDecision consumes the held decision and commits one transition.
// Approve starts ToolsRunning; reject commits Failed using the recorded reason.
// No external I/O runs here. The host may execute tools only after nil error AND
// ToolsRunning from this call, never by inspecting a retry's returned State alone.
func (g *PauseGate) ResolveDecision(runID, requestID string) (State, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	// Preserve Run.Apply's cancellation observation and terminal-first behavior.
	if g.run.Context().Err() != nil {
		state, err := g.run.Apply(Event{Kind: Cancel})
		if terminal(state.Phase) {
			g.request, g.decision = nil, nil
		}
		return state, err
	}
	current := g.run.Snapshot()
	if strings.TrimSpace(runID) == "" || strings.TrimSpace(requestID) == "" {
		return current, ErrInvalidDecision
	}
	if g.request == nil {
		return current, ErrNoPause
	}
	if runID != g.request.Checkpoint.State.RunID || requestID != g.request.ID {
		return current, ErrDecisionMismatch
	}
	if g.decision == nil {
		return current, ErrDecisionRequired
	}
	event := Event{Kind: StartTools}
	if g.decision.Outcome == DecisionReject {
		event = Event{Kind: Abort, Reason: g.decision.Reason}
	}
	state, err := g.run.Apply(event)
	if err == nil || terminal(state.Phase) {
		g.request, g.decision = nil, nil
	}
	return state, err
}
