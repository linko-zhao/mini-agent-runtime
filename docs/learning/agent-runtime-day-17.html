Checkpoint 边界与快照

今天实现有边界限制的内存 Checkpoint，让宿主知道“捕获了哪一步”，并保留一份不会随运行继续改变的状态副本。

今天只解决什么？

仍然处理“读取 doc-1”。Day16已经有独立 Run 和安全更新入口，但任何阶段都能读 Snapshot；模型或工具进行中取得的副本，并不适合直接当作下一步的保存候选。

今天新增 Checkpoint()：在确定的稳定阶段返回“边界标签 + State副本”，进行中的阶段明确报错。这样，未来保存层可以先获得有明确语义的输入。

完成后能区分：读取观察快照、捕获 Checkpoint 候选、存储确认、恢复执行。这四件事没有合并成一次方法调用。

本日只捕获内存候选，不接存储、不暂停驱动、不恢复、不自动重放，也不改造旧 Agent.Run/RunWithState。

先理解三个概念

边界：状态机确认的一个停靠位置

Ready 是模型调用前或一批结果已被接纳后；ToolsPending 是模型请求已接受、宿主尚未记录工具开始的阶段。它们比“任意时刻复制内存”更容易解释。

本日仅依赖 Run 记录的 Phase 判断边界。它不能证明其他代码没有绕过驱动调用外部工具，宿主仍须遵守前序单驱动与授权规则。

Checkpoint 候选：带边界标签的独立副本

它把同一时刻的标签和 State 放在一起。捕获后 Run 可以继续前进，候选保留旧阶段，不会跟着变。

Boundary 是分类，不是保存ID、序号或恢复令牌。State 继续使用 Day15 的消息与调用结构，不重建另一套模型。

确认：保存成功与外部执行是否发生

拿到内存副本没有磁盘或数据库确认。即使未来保存成功，也不能直接推断外部工具没有执行过。

今天先定义候选边界；Day18再加入存储与版本控制。遇到不确定调用，仍需后续恢复、确认与幂等设计。

为什么拒绝“进行中”，又允许终态？

ModelRunning 与 ToolsRunning 尚没有已接纳结果。若直接当成待执行边界，会混淆“尚未调用”与“调用结果不确定”。本日选择拒绝，而非假装实现了恢复策略。

终态可捕获是为了归档观察，不代表可继续执行。Failed/Cancelled 可能保留 Pending；它们不能被改成 Ready 后重新交回 Run。

Ready 也不保证下次 StartModel 会成功：预算可能耗尽，context可能已取消，授权或依赖也可能变化。边界分类不授予执行权限。

字段与方法：每一个承诺都有限定

CheckpointBoundary 与三个常量

CheckpointReady="ready" 对应 Ready；CheckpointBeforeTools="before_tools" 对应 ToolsPending；CheckpointTerminal="terminal" 对应 Completed、Failed、Cancelled。

终态的具体原因仍看 State.Phase/Failure。标签不会替换 Phase，也不表示幂等键、唯一编号或版本。

Checkpoint：Boundary + State

Boundary 和 State 来自同一次受保护读取，不能分两次读取后拼接。State 是独立副本，调用者可以修改自己的数据，但这不会修改 Run。

公开字段方便宿主检查；它不是可信凭据。调用者能手动造出或改坏 Checkpoint，本日没有外部数据校验/反序列化入口，不能把伪造对象当作可恢复状态。

复用的 State 字段

RunID 是本次运行身份；Phase 是阶段；Step 是已开始的模型轮次；MaxSteps 是预算。两者都是轮次计数，不是保存版本。

Messages 是已接纳历史，内含 ToolCalls/Arguments；Pending 是待确认调用；Result 是已完成文本，Failure 是原状态的受控原因。每个字段原样保留，不重新解释或自动清理。

State 不含 context、锁、Model、Tool、MCP会话、cancel函数或原始 Go error；这些不能靠复制 State 来恢复。

Run.Checkpoint() (Checkpoint, error)

接收 Day16 NewRun 返回的 Run 指针，无额外参数。合法阶段返回候选和 nil；其他阶段返回零 Checkpoint 与 ErrCheckpointBoundary，可用 errors.Is 识别。

只读取，不增加 Step、不清 Pending、不执行 I/O、不调用 Apply，也不观察 ctx.Err。即使 ctx 已取消，只要状态还在稳定阶段，捕获仍可成功；取消状态由下一次 Apply 记录。

它与 Apply/Snapshot 可并发，分类与复制是同一瞬间的内存观察。锁不跨越方法返回和后续保存；等待锁不可用 context 中断，克隆成本随历史增长。

Checkpoint.Clone() Checkpoint

返回另一份独立副本，Boundary原样保留，State沿前序深拷贝。零值可克隆；克隆不修复、不验证也不签发任何权限。

调用方不得在 Clone 读取源对象的同时修改其切片；不同读者应先各自持有独立副本。对象包含私密输入/参数/正文，不是公开审计事件。

// Package runstate models in-memory transitions. It is not a checkpoint store.
package runstate

import (
	"errors"
	"strings"

	"github.com/linko-zhao/mini-agent-runtime/internal/model"
)

type Phase string

const (
	Ready        Phase = "ready"
	ModelRunning Phase = "model_running"
	ToolsPending Phase = "tools_pending"
	ToolsRunning Phase = "tools_running"
	Completed    Phase = "completed"
	Failed       Phase = "failed"
	Cancelled    Phase = "cancelled"
)

type EventKind string

const (
	StartModel    EventKind = "start_model"
	ModelReturned EventKind = "model_returned"
	StartTools    EventKind = "start_tools"
	ToolsReturned EventKind = "tools_returned"
	Abort         EventKind = "abort"
	Cancel        EventKind = "cancel"
)

var (
	ErrTransition = errors.New("runstate: invalid transition")
	ErrMaxSteps   = errors.New("runstate: max model rounds exceeded")
)

type State struct {
	RunID           string
	Phase           Phase
	Step, MaxSteps  int
	Messages        []model.Message
	Pending         []model.ToolCall
	Result, Failure string
}
type Event struct {
	Kind     EventKind
	Response *model.Response
	Results  []model.Message
	Reason   string
}

func New(runID, input string, maxSteps int) (State, error) {
	if strings.TrimSpace(runID) == "" || maxSteps <= 0 {
		return State{}, ErrTransition
	}
	return State{RunID: runID, Phase: Ready, MaxSteps: maxSteps, Messages: []model.Message{{Role: "user", Content: input}}}, nil
}
func cloneCalls(calls []model.ToolCall) []model.ToolCall {
	if calls == nil {
		return nil
	}
	out := append([]model.ToolCall{}, calls...)
	for i := range out {
		out[i].Arguments = append([]byte(nil), out[i].Arguments...)
	}
	return out
}
func cloneMessages(ms []model.Message) []model.Message {
	if ms == nil {
		return nil
	}
	out := append([]model.Message{}, ms...)
	for i := range out {
		out[i].ToolCalls = cloneCalls(out[i].ToolCalls)
	}
	return out
}
func cloneState(s State) State {
	s.Messages = cloneMessages(s.Messages)
	s.Pending = cloneCalls(s.Pending)
	return s
}
func terminal(p Phase) bool { return p == Completed || p == Failed || p == Cancelled }

// Advance has no I/O. The host performs calls between start/returned events.
// It accepts states from New/Advance and never mutates input state/event buffers.
func Advance(current State, e Event) (State, error) {
	if terminal(current.Phase) {
		return State{}, ErrTransition
	}
	next := cloneState(current)
	switch e.Kind {
	case StartModel:
		if current.Phase != Ready {
			return State{}, ErrTransition
		}
		if current.Step >= current.MaxSteps {
			return State{}, ErrMaxSteps
		}
		next.Step++
		next.Phase = ModelRunning
	case ModelReturned:
		if current.Phase != ModelRunning || e.Response == nil || e.Response.Message.Role != "assistant" {
			return State{}, ErrTransition
		}
		msg := e.Response.Message
		ids := map[string]bool{}
		for _, call := range msg.ToolCalls {
			if call.ID == "" || strings.TrimSpace(call.Name) == "" || ids[call.ID] {
				return State{}, ErrTransition
			}
			ids[call.ID] = true
		}
		next.Messages = append(next.Messages, cloneMessages([]model.Message{msg})...)
		if len(msg.ToolCalls) == 0 {
			next.Phase = Completed
			next.Result = msg.Content
		} else {
			next.Phase = ToolsPending
			next.Pending = cloneCalls(msg.ToolCalls)
		}
	case StartTools:
		if current.Phase != ToolsPending {
			return State{}, ErrTransition
		}
		next.Phase = ToolsRunning
	case ToolsReturned:
		if current.Phase != ToolsRunning || len(e.Results) != len(current.Pending) {
			return State{}, ErrTransition
		}
		for i, msg := range e.Results {
			if msg.Role != "tool" || msg.ToolCallID != current.Pending[i].ID {
				return State{}, ErrTransition
			}
		}
		next.Messages = append(next.Messages, cloneMessages(e.Results)...)
		next.Pending = nil
		next.Phase = Ready
	case Abort:
		if strings.TrimSpace(e.Reason) == "" {
			return State{}, ErrTransition
		}
		next.Phase = Failed
		next.Failure = e.Reason
	case Cancel:
		next.Phase = Cancelled
		next.Failure = "cancelled"
	default:
		return State{}, ErrTransition
	}
	return next, nil
}

internal/runstate/run.go

package runstate

import (
	"context"
	"sync"
)

// Run owns one in-memory State. Use its pointer; do not copy it after use.
// The zero value is not usable; construct with NewRun.
type Run struct {
	ctx   context.Context
	mu    sync.Mutex
	state State
}

// NewRun retains ctx for cancellation/deadlines, not for storing State.
// A cancelled context rejects construction; invalid identity/budget uses ErrTransition.
func NewRun(ctx context.Context, runID, input string, maxSteps int) (*Run, error) {
	if ctx == nil {
		return nil, ErrTransition
	}
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	s, err := New(runID, input, maxSteps)
	if err != nil {
		return nil, err
	}
	return &Run{ctx: ctx, state: s}, nil
}

// Context returns the original context. The host owns any cancel function.
// Model/tool I/O must use this context outside Apply, never while holding its lock.
func (r *Run) Context() context.Context { return r.ctx }

// Snapshot returns an independent copy without triggering transitions.
func (r *Run) Snapshot() State {
	r.mu.Lock()
	defer r.mu.Unlock()
	return cloneState(r.state)
}

// Apply commits exactly one valid event, or returns the unchanged current copy.
// For a nonterminal Run, observed context cancellation commits Cancel and rejects
// the event with the original context error. A terminal State is never overwritten.
// This serializes transitions, not a snapshot -> external I/O -> Apply transaction.
func (r *Run) Apply(e Event) (State, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	if terminal(r.state.Phase) {
		return cloneState(r.state), ErrTransition
	}
	if err := r.ctx.Err(); err != nil {
		next, transitionErr := Advance(r.state, Event{Kind: Cancel})
		if transitionErr != nil {
			return cloneState(r.state), transitionErr
		}
		r.state = next
		return cloneState(r.state), err
	}
	next, err := Advance(r.state, e)
	if err != nil {
		return cloneState(r.state), err
	}
	r.state = next
	return cloneState(r.state), nil
}

func TestDay17CancellationAndTerminal(t *testing.T) {
	ctx, cancel := context.WithCancel(context.Background())
	defer cancel()
	r := run17(t, ctx)
	event17(t, r, runstate.Event{Kind: runstate.StartModel})
	event17(t, r, runstate.Event{Kind: runstate.ModelReturned, Response: response17("call-1")})
	cancel()
	// Capture is a read; unlike Apply, it does not observe cancellation.
	checkpoint17(t, r, runstate.CheckpointBeforeTools)
	if _, err := r.Apply(runstate.Event{Kind: runstate.StartTools}); !errors.Is(err, context.Canceled) {
		t.Fatal(err)
	}
	cp := checkpoint17(t, r, runstate.CheckpointTerminal)
	if cp.State.Phase != runstate.Cancelled || cp.State.Failure != "cancelled" || len(cp.State.Pending) != 1 {
		t.Fatal(cp)
	}
	// Terminal capture retains unconfirmed work but never reopens the Run.
	for _, kind := range []runstate.EventKind{runstate.Abort, runstate.Cancel} {
		other := run17(t, context.Background())
		event17(t, other, runstate.Event{Kind: runstate.StartModel})
		event17(t, other, runstate.Event{Kind: runstate.ModelReturned, Response: response17("pending")})
		event17(t, other, runstate.Event{Kind: runstate.StartTools})
		event17(t, other, runstate.Event{Kind: kind, Reason: "controlled_failure"})
		terminal := checkpoint17(t, other, runstate.CheckpointTerminal)
		if len(terminal.State.Pending) != 1 || len(terminal.State.Messages) != 2 {
			t.Fatal(terminal)
		}
		if kind == runstate.Abort && (terminal.State.Phase != runstate.Failed || terminal.State.Failure != "controlled_failure") {
			t.Fatal(terminal)
		}
		if kind == runstate.Cancel && terminal.State.Phase != runstate.Cancelled {
			t.Fatal(terminal)
		}
	}
}

func TestDay17ConcurrentCapture(t *testing.T) {
	r := run17(t, context.Background())
	start := make(chan struct{})
	var wg sync.WaitGroup
	for n := 0; n < 4; n++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			<-start
			for i := 0; i < 250; i++ {
				cp, err := r.Checkpoint()
				if err != nil {
					if !errors.Is(err, runstate.ErrCheckpointBoundary) {
						t.Error(err)
					}
					runtime.Gosched()
					continue
				}
				switch cp.Boundary {
				case runstate.CheckpointReady:
					if cp.State.Phase != runstate.Ready || len(cp.State.Pending) != 0 || len(cp.State.Messages) != 1+2*cp.State.Step {
						t.Error("mixed Ready snapshot", cp)
					}
				case runstate.CheckpointBeforeTools:
					if cp.State.Phase != runstate.ToolsPending || len(cp.State.Pending) != 1 || len(cp.State.Messages) != 2*cp.State.Step || cp.State.Pending[0].ID != fmt.Sprintf("call-%d", cp.State.Step) {
						t.Error("mixed tools snapshot", cp)
					}
				case runstate.CheckpointTerminal:
					if cp.State.Phase != runstate.Completed || len(cp.State.Messages) != 2*cp.State.Step {
						t.Error("mixed terminal snapshot", cp)
					}
				default:
					t.Error("unknown boundary", cp)
				}
				cp.State.Messages[0].Content = "reader-owned"
				runtime.Gosched()
			}
		}()
	}
	close(start)
	for i := 1; i <= 30; i++ {
		id := fmt.Sprintf("call-%d", i)
		event17(t, r, runstate.Event{Kind: runstate.StartModel})
		event17(t, r, runstate.Event{Kind: runstate.ModelReturned, Response: response17(id)})
		event17(t, r, runstate.Event{Kind: runstate.StartTools})
		event17(t, r, runstate.Event{Kind: runstate.ToolsReturned, Results: []model.Message{{Role: "tool", ToolCallID: id, Content: "ok"}}})
	}
	event17(t, r, runstate.Event{Kind: runstate.StartModel})
	event17(t, r, runstate.Event{Kind: runstate.ModelReturned, Response: &model.Response{Message: model.Message{Role: "assistant", Content: "done"}}})
	wg.Wait()
	cp := checkpoint17(t, r, runstate.CheckpointTerminal)
	if cp.State.Step != 31 || cp.State.Messages[0].Content != "读取 doc-1" {
		t.Fatal(cp)
	}
}

package runstate

import "errors"

type CheckpointBoundary string

const (
	CheckpointReady       CheckpointBoundary = "ready"
	CheckpointBeforeTools CheckpointBoundary = "before_tools"
	CheckpointTerminal    CheckpointBoundary = "terminal"
)

var ErrCheckpointBoundary = errors.New("runstate: checkpoint requires a stable boundary")

// Checkpoint is an in-memory candidate, not a storage acknowledgement or resume token.
// State uses the existing message/call contract. Boundary classifies State.Phase.
type Checkpoint struct {
	Boundary CheckpointBoundary
	State    State
}

// Clone copies nested mutable state. It does not validate or authorize a checkpoint.
func (c Checkpoint) Clone() Checkpoint {
	c.State = cloneState(c.State)
	return c
}

// Checkpoint samples boundary and state under the same lock.
// It does not observe context cancellation, advance state, pause the driver,
// perform I/O, or promise that an external tool has not already taken effect.
func (r *Run) Checkpoint() (Checkpoint, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	var boundary CheckpointBoundary
	switch r.state.Phase {
	case Ready:
		boundary = CheckpointReady
	case ToolsPending:
		boundary = CheckpointBeforeTools
	case Completed, Failed, Cancelled:
		boundary = CheckpointTerminal
	default:
		return Checkpoint{}, ErrCheckpointBoundary
	}
	return Checkpoint{Boundary: boundary, State: cloneState(r.state)}, nil
}
