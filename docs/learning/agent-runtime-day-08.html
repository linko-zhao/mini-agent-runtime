今天只解决一个问题

实现 Registry（工具注册表）：让 Runtime 根据工具名称，找到可以执行的工具；同时向模型提供工具说明。

用户问：“查找并阅读 Runtime 工具契约。”模型无法直接访问你的资料库，需要借助搜索工具和读取工具。

如果每增加一个工具，就往 Loop 中增加一个业务分支，循环很快会混入搜索、数据库和 HTTP 细节。

今天的设计：Loop 只按名称查表；每个工具自己处理业务。增加工具时，实现统一接口，再注册即可。

本日实现范围：描述与执行接口、注册表、接回旧接口的适配层。Store 和三轮对话用于理解整条线路，复用已有参考夹具，不另写搜索算法。

前置概念：Model.Generate 是“请求一次模型”；Loop 是“反复请求模型并处理工具调用”；context 用来传递本次请求的取消和超时。Day 01–07 的消息与旧 Tool 接口继续使用。

先分清三个概念

工具说明 Spec：给模型看的“使用说明书”

它写明工具叫什么、什么时候用、接收什么参数。

例如：get_document，按文档 ID 读取正文，参数为 {"id":"doc-1"}。说明本身不包含正文。

可调用工具 Invokable：真正做事的对象

Meta 返回说明；Invoke 才执行一次业务。

读取说明时不访问资料库。运行 Invoke 时，才把参数和 context 交给后端。

注册表 Registry：按名字找工具的容器

保存“get_document → 读取工具对象”这样的对应关系。

模型给出名称后，Runtime 查询容器，不需要知道底层使用数据库还是 HTTP。

图 1 · 谁负责什么？

Store 是什么？工具需要的后端接口，例如 Search 和 Get。测试用 FakeStore，线上换成真实实现，Loop 不变。

为什么同时有 Spec 和工具对象？模型需要的是说明，Runtime 需要的是对象。把 Go 对象或凭据塞进模型输入没有用，也会混淆职责。

用一个输入走完运行过程

先装配，再运行。装配是启动前接好线路；运行是处理用户的一次请求。

装配：只准备能力

① Host 创建 SearchKnowledge 和 GetDocument，注入 Store。

② Register 读取每个工具的 Meta，保存描述快照与执行对象。

③ Tools 把新接口转换成旧 Tool 接口，交给 Agent.New；模型得到描述。

到这里，资料库访问次数仍应是 0。

图 2 · 从检索到回答

名称与调用 ID 不一样：名称找到哪种能力；调用 ID 对应哪一次请求。两次调用同一个工具时，结果仍须各自关联。

一个失败反例

请求名称是 missing_toolLookup 返回 nil,false。Loop 按既有协议处理未知工具，不会因此去执行 get_document。

脚本 Mock 能验证消息线路接对了，不能证明真实模型会选择正确工具。真实模型效果要另外验证。

字段和方法为什么这样设计？

Spec 的三个字段

Name 是查表键，例如 get_document；注册后保持原样，不自动修剪或更名。

Description 说明用途，供模型选择；本课允许空字符串，但实际应写清楚。

InputSchema 是 JSON 格式的参数说明。它是字节切片，必须复制，才能避免外部修改影响已注册描述。

本课只检查 JSON 是对象且顶层 type 为 object，不实现完整 JSON Schema 校验。实际参数仍由 Invoke 校验。

registration：一份说明，一份执行对象

spec 保存注册时的说明快照；target 保存原工具对象。

说明不再反复请求 Meta；执行时仍调用原对象。对象自身的业务状态不会被深拷贝。

Registry 的两个字段

entries 按名称保存 registration。重复名必须拒绝，否则同一名称可能悄悄执行另一种实现。

mu 保护 entries 的并发读写。不要在持锁时调用外部 Meta：慢后端会阻塞所有查表操作。

锁只保护注册表，不保证注入工具的 Invoke 并发安全。Registry 使用指针传递，使用后不要复制含锁的结构体。

Register(ctx, t)：接入一个工具

输入是本次 context 和工具对象；成功返回 nil，状态新增一项。

先检查已取消，再读取 Meta、校验说明，最后在锁内检查重名并保存。Meta 失败保留错误原因，不注册半成品。

Lookup(name) 与 Specs(visible)：两种查询

Lookup 返回原执行对象和是否找到；不改变状态。

Specs 返回排序后的说明副本。nil 表示全部，非 nil 空切片表示一个也不展示。

例如注册 a、b，只展示 a 后，Lookup("b") 仍能找到 b。可见性不等于执行权限，授权留到 Day 11。

Adapt 与 Tools：兼容已有 Loop

旧接口使用 Name / Definition / Execute；新接口使用 Meta / Invoke。

适配层让 Definition 返回保存的描述，让 Execute 调用 Invoke。因而 Agent.New 和 Run 无须改签名。

Tools 为全部注册对象生成一份独立 map；调用方删除其中一项，不会删除注册表里的项。

Definitions(specs)：只做字段映射

Name → Name，Description → Description，InputSchema → Parameters。

复制 Parameters 的字节；它只生成模型描述，不调用工具，也不改变注册表。

行为契约：你的实现要满足什么？

按这些规则实现即可；测试不能额外要求隐藏算法。未约定的错误文本不必与参考代码相同。

R1 · 注册与查找

NewRegistry 返回可用指针；Registry 零值也能查询与注册。成功注册只调用 Meta 一次，不调用 Invoke。Lookup 找不到时返回 nil,false。

验证：TestDay08RegisterLookup / TestDay08ZeroValue

R2 · 注册失败不污染状态

拒绝 nil 接口、空/纯空白名称、非法 JSON、非对象 JSON、缺少或非 object 的 type。重复名称报错并保留原对象。名称有效后原样保存；不自动修剪。Description 可为空；不承诺识别含 nil 指针的非 nil 接口。

验证：TestDay08RejectInvalid / TestDay08RegisterLookup

R3 · 依赖错误与取消

Meta 失败保留 errors.Is 可识别的原因。Register 入场时 ctx 已取消，直接返回 context.Canceled，不调用 Meta。Meta 收到原 context，负责期间的合作取消；本课不保证调用开始后的取消能回滚注册。没有独立超时配置。

验证：TestDay08RejectInvalid / TestDay08CancelledRegistration

R4 · 可见集合

Specs(nil) 全部；Specs([]string{}) 零个；选择项去重后按名称升序。未知名称报错且不返回部分结果。不修改 visible，不删除注册，不再调用 Meta 或 Invoke。

验证：TestDay08Visibility

R5 · 描述快照

注册输入、Specs 输出、Definitions 输出的 schema 字节互不共享。字段映射准确；空输入产生零个模型描述。工具对象保持原身份，修改业务状态不会得到隔离。

验证：TestDay08Snapshots

R6 · 兼容桥接

Adapt 拒绝非法输入并保存一次 Meta 快照；Name/Definition 对应原说明，Definition 返回副本。Execute 将本次 ctx、参数交给 Invoke，返回结果/错误原因。不额外重试或吞掉取消。Tools 复用注册快照、返回独立 map，并提供 DescribedTool。

验证：TestDay08LegacyBridge

R7 · 并发边界

允许不同 goroutine 注册不同工具并查询 Registry；集合不丢项且 race 检查通过。锁不覆盖业务 Invoke；fake 各自独立。

验证：TestDay08ConcurrentRegistry

package tool_test

import (
	"context"
	"encoding/json"

// fake 只记录行为，不连接模型、资料库或网络。
type day08Fake struct {
	spec               tool.Spec
	metaErr, invokeErr error
	metas, invokes     int
	gotCtx, metaCtx    context.Context
	gotArgs            json.RawMessage
}

func day08New(name string) *day08Fake {
	return &day08Fake{spec: tool.Spec{
		Name: name, Description: "读取资料",
		InputSchema: json.RawMessage(`{"type":"object"}`),
	}}
}
func (f *day08Fake) Meta(ctx context.Context) (tool.Spec, error) {
	f.metas++
	f.metaCtx = ctx
	return f.spec, f.metaErr
}
func (f *day08Fake) Invoke(ctx context.Context, args json.RawMessage) (string, error) {
	f.invokes++
	f.gotCtx, f.gotArgs = ctx, append(json.RawMessage(nil), args...)
	return "doc-1", f.invokeErr
}
func day08Register(t *testing.T, r *tool.Registry, f *day08Fake) {
	t.Helper()
	if err := r.Register(context.Background(), f); err != nil {
		t.Fatal(err)
	}
}
func day08Names(specs []tool.Spec) []string {
	names := make([]string, len(specs))
	for i, s := range specs {
		names[i] = s.Name
	}
	return names
}

func TestDay08RegisterLookup(t *testing.T) {
	r := tool.NewRegistry()
	if r == nil {
		t.Fatal("构造函数返回 nil")
	}
	f := day08New("get_document")
	type key struct{}
	ctx := context.WithValue(context.Background(), key{}, "register-1")
	if err := r.Register(ctx, f); err != nil {
		t.Fatal(err)
	}
	if f.metaCtx != ctx {
		t.Fatal("Meta 必须收到本次注册 context")
	}
	if f.metas != 1 || f.invokes != 0 {
		t.Fatal("注册只读一次说明，不执行业务")
	}
	got, ok := r.Lookup("get_document")
	if !ok || got != f {
		t.Fatal("名称应查到原工具对象")
	}
	if got, ok := r.Lookup("missing"); ok || got != nil {
		t.Fatal("未知工具应为 nil,false")
	}
	if err := r.Register(context.Background(), day08New("get_document")); err == nil {
		t.Fatal("重复名称必须报错")
	}
	if got, _ := r.Lookup("get_document"); got != f {
		t.Fatal("重复注册不能覆盖原对象")
	}
	if f.metas != 1 || f.invokes != 0 {
		t.Fatal("查询不得重新 Meta 或 Invoke")
	}
	raw := day08New(" a ")
	raw.spec.Description = ""
	day08Register(t, r, raw)
	if got, ok := r.Lookup(" a "); !ok || got != raw {
		t.Fatal("合法名称应保持原样，说明允许为空")
	}
}

func TestDay08RejectInvalid(t *testing.T) {
	for _, tc := range []struct{ name, toolName, schema string }{
		{"empty-name", "", `{"type":"object"}`},
		{"blank-name", " \t", `{"type":"object"}`},
		{"bad-json", "x", `{`},
		{"null-schema", "x", `null`},
		{"array-schema", "x", `[]`},
		{"wrong-type", "x", `{"type":"string"}`},
		{"missing-type", "x", `{}`},
	} {
		t.Run(tc.name, func(t *testing.T) {
			r := tool.NewRegistry()
			f := day08New(tc.toolName)
			f.spec.InputSchema = json.RawMessage(tc.schema)
			if err := r.Register(context.Background(), f); err == nil {
				t.Fatal("非法说明被接受")
			}
			specs, err := r.Specs(nil)
			if err != nil || len(specs) != 0 || f.invokes != 0 {
				t.Fatal("失败注册污染了状态")
			}
			if _, err := tool.Adapt(context.Background(), f); err == nil {
				t.Fatal("Adapt 也应校验说明")
			}
		})
	}
	r := tool.NewRegistry()
	if err := r.Register(context.Background(), nil); err == nil {
		t.Fatal("应拒绝 nil 接口")
	}
	if _, err := tool.Adapt(context.Background(), nil); err == nil {
		t.Fatal("Adapt 应拒绝 nil 接口")
	}
	sentinel := errors.New("metadata unavailable")
	f := day08New("x")
	f.metaErr = sentinel
	if err := r.Register(context.Background(), f); !errors.Is(err, sentinel) {
		t.Fatalf("丢失原因: %v", err)
	}
	if _, err := tool.Adapt(context.Background(), f); !errors.Is(err, sentinel) {
		t.Fatalf("丢失原因: %v", err)
	}
	specs, err := r.Specs(nil)
	if err != nil || len(specs) != 0 {
		t.Fatal("Meta 失败不得注册")
	}
}

func TestDay08CancelledRegistration(t *testing.T) {
	ctx, cancel := context.WithCancel(context.Background())
	cancel()
	r, f := tool.NewRegistry(), day08New("x")
	if err := r.Register(ctx, f); !errors.Is(err, context.Canceled) {
		t.Fatalf("取消原因错误: %v", err)
	}
	if f.metas != 0 || f.invokes != 0 {
		t.Fatal("已取消时不得调用工具")
	}
	if _, ok := r.Lookup("x"); ok {
		t.Fatal("已取消调用不应注册")
	}
}

func TestDay08Visibility(t *testing.T) {
	r := tool.NewRegistry()
	a, b := day08New("a"), day08New("b")
	day08Register(t, r, b)
	day08Register(t, r, a)
	for _, tc := range []struct {
		name          string
		visible, want []string
	}{
		{"all", nil, []string{"a", "b"}},
		{"none", []string{}, []string{}},
		{"one", []string{"b"}, []string{"b"}},
		{"sorted-deduplicated", []string{"b", "a", "b"}, []string{"a", "b"}},
	} {
		t.Run(tc.name, func(t *testing.T) {
			before := append([]string(nil), tc.visible...)
			got, err := r.Specs(tc.visible)
			if err != nil || !reflect.DeepEqual(day08Names(got), tc.want) {
				t.Fatalf("got %v, %v", day08Names(got), err)
			}
			if len(before) > 0 && !reflect.DeepEqual(before, tc.visible) {
				t.Fatal("修改了调用方 visible")
			}
		})
	}
	if got, err := r.Specs([]string{"a", "missing"}); err == nil || len(got) != 0 {
		t.Fatal("未知名称应报错且不返回部分结果")
	}
	if got, ok := r.Lookup("a"); !ok || got != a {
		t.Fatal("可见性筛选不能删除执行对象")
	}
	if a.invokes+b.invokes != 0 || a.metas+b.metas != 2 {
		t.Fatal("列说明应只使用快照")
	}
}

func TestDay08Snapshots(t *testing.T) {
	r, f := tool.NewRegistry(), day08New("a")
	day08Register(t, r, f)
	f.spec.Name, f.spec.Description = "changed", "changed"
	f.spec.InputSchema[0] = 'x'
	specs, err := r.Specs(nil)
	if err != nil || len(specs) != 1 || specs[0].Name != "a" || specs[0].Description != "读取资料" || !json.Valid(specs[0].InputSchema) {

package tool

import (
	"context"
	"encoding/json"
	"fmt"

	"github.com/linko-zhao/mini-agent-runtime/internal/model"
)

// Spec 只包含供模型选择能力的元信息，不含执行函数或凭据。
type Spec struct {
	Name, Description string
	InputSchema       json.RawMessage
}
type Described interface {
	Meta(context.Context) (Spec, error)
}
type Invokable interface {
	Described
	Invoke(context.Context, json.RawMessage) (string, error)
}

// Call 沿用最早建立的 ToolCall 数据结构，避免第二套调用协议。
type Call = model.ToolCall

func cloneSpec(s Spec) Spec { s.InputSchema = append(json.RawMessage(nil), s.InputSchema...); return s }

// Adapt 将 Day 08 能力接入 Day 01 的 Tool/DescribedTool，元信息在适配时快照。
// Invoke 仍接收每次执行的 context，而非构造时的 context。
func Adapt(ctx context.Context, t Invokable) (DescribedTool, error) {
	if t == nil {
		return nil, fmt.Errorf("tool: nil invokable")
	}
	s, err := t.Meta(ctx)
	if err != nil {
		return nil, err
	}
	if err = validateSpec(s); err != nil {
		return nil, err
	}
	return &legacyAdapter{spec: cloneSpec(s), target: t}, nil
}

type legacyAdapter struct {
	spec   Spec
	target Invokable
}

func (t *legacyAdapter) Name() string { return t.spec.Name }
func (t *legacyAdapter) Definition() model.ToolDefinition {
	return model.ToolDefinition{Name: t.spec.Name, Description: t.spec.Description, Parameters: append(json.RawMessage(nil), t.spec.InputSchema...)}
}
func (t *legacyAdapter) Execute(ctx context.Context, args json.RawMessage) (string, error) {
	return t.target.Invoke(ctx, args)
}

package tool

import (
	"context"
	"encoding/json"
	"fmt"
	"sort"
	"strings"
	"sync"

	"github.com/linko-zhao/mini-agent-runtime/internal/model"
)

type registration struct {
	spec   Spec
	target Invokable
}

// Registry 保存完整执行集合。Specs 为模型可见集合的独立快照，不授予执行权限。
type Registry struct {
	mu      sync.RWMutex
	entries map[string]registration
}

func NewRegistry() *Registry { return &Registry{entries: make(map[string]registration)} }
func validateSpec(s Spec) error {
	if strings.TrimSpace(s.Name) == "" {
		return fmt.Errorf("tool: empty name")
	}
	var schema map[string]any
	if err := json.Unmarshal(s.InputSchema, &schema); err != nil || schema["type"] != "object" {
		return fmt.Errorf("tool %q: expected object input schema", s.Name)
	}
	return nil
}

// Register 读取一次元信息；不调用 Invoke。重复名称绝不覆盖。
func (r *Registry) Register(ctx context.Context, t Invokable) error {
	if err := ctx.Err(); err != nil {
		return err
	}
	if t == nil {
		return fmt.Errorf("tool: nil invokable")
	}
	s, err := t.Meta(ctx)
	if err != nil {
		return err
	}
	if err = validateSpec(s); err != nil {
		return err
	}
	r.mu.Lock()
	defer r.mu.Unlock()
	if r.entries == nil {
		r.entries = make(map[string]registration)
	}
	if _, exists := r.entries[s.Name]; exists {
		return fmt.Errorf("tool: duplicate name %q", s.Name)
	}
	r.entries[s.Name] = registration{spec: cloneSpec(s), target: t}
	return nil
}
func (r *Registry) Lookup(name string) (Invokable, bool) {
	r.mu.RLock()
	defer r.mu.RUnlock()
	entry, ok := r.entries[name]
	return entry.target, ok
}

// Specs(nil) 枚举全部；非 nil 空切片返回空集合。未知名称返回错误。
// 返回值按名称排序且深拷贝 Schema；调用方修改不会改变注册表。
func (r *Registry) Specs(visible []string) ([]Spec, error) {
	r.mu.RLock()
	defer r.mu.RUnlock()
	names := append([]string(nil), visible...)
	if visible == nil {
		for name := range r.entries {
			names = append(names, name)
		}
	}
	sort.Strings(names)
	out := make([]Spec, 0, len(names))
	last := ""
	for _, name := range names {
		if name == last {
			continue
		}
		last = name
		e, ok := r.entries[name]
		if !ok {
			return nil, fmt.Errorf("tool: unregistered name %q", name)
		}
		out = append(out, cloneSpec(e.spec))
	}
	return out, nil
}

// Tools 为旧 Agent 构造 API 提供所有已注册工具的适配快照。
func (r *Registry) Tools() map[string]Tool {
	r.mu.RLock()
	defer r.mu.RUnlock()
	out := make(map[string]Tool, len(r.entries))
	for name, e := range r.entries {
		out[name] = &legacyAdapter{spec: cloneSpec(e.spec), target: e.target}
	}
	return out
}
func Definitions(specs []Spec) []model.ToolDefinition {
	defs := make([]model.ToolDefinition, 0, len(specs))
	for _, s := range specs {
		defs = append(defs, model.ToolDefinition{Name: s.Name, Description: s.Description, Parameters: append(json.RawMessage(nil), s.InputSchema...)})
	}
	return defs
}
