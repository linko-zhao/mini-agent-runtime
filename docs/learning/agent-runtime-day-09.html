任务 B · 30 分钟：严格解析 calculator 参数

internal/tool/calculator.gointernal/tool/calculator_test.go

  1. 解码为指针字段或显式跟踪字段存在性，区分缺失与合法零值；JSON 标签用小写 a、b。
  2. 用 Decoder.DisallowUnknownFields 拒绝额外字段，并在成功解码后再尝试读取一个值，要求结果为 EOF，拒绝尾随 JSON。
  3. 拒绝 null、数组、字符串等非对象输入；错误应稳定可断言。
  4. 使用 int 加法前检查上下界，或采用明确范围的整数类型；溢出不得悄悄回绕。
  5. 检查 context 取消是否应阻止计算；若当前操作纯同步且极短，在本次记录策略，不为形式增加 goroutine。
